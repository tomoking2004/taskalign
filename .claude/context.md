# 視覚言語モデルにおけるタスク類似性に基づく内部表現整合学習に関する検討

中野 友晴 ／ 2026-11-26 時点

## 0. 要約

視覚言語モデル（VLM）の内部表現は，出力が同じでも入力の揺らぎで大きく動きうる（Wani ら）——出力の頑健性は，表現の頑健性を意味しない．本研究は，これに隣接する問い——同じ解き方で解ける質問どうしの内部表現は，互いに近いか——から入る．GQA の各質問に付く functional program の演算子列を**タスク署名**と呼び，署名が一致する質問の中間層表現（第16層，質問を読み終えた位置）を近づける補助損失を，通常の学習に足す——これを**整合**と呼ぶ（→ [§3](#3-手法)）．**中心の問いは，こうして内部表現に作り込んだ署名の構造が，答えの生成に使われるかである**（→ [§1.2](#12-本研究の問い)）．整合の有無とラベルの意味だけを変えた三つの群を，乱数種3つで学習した（計9回，→ [§4](#4-実験設定)）．

**主結果は三つである．**

1. **整合は，第16層から署名を線形に読み取れる度合いを大きく上げる**——82.9% → 95.9%（+13.0pt）．この増分は，ラベルを無作為に並べ替えると起きず，質問文の言い回しでは説明されない（→ [§5.1](#51-署名の読み取りやすさは大きく上がる)）．
2. **そのあいだ，質問応答の正解率はほとんど動かない**——53.5 → 53.5，低下は最大でも 1.81pt．内部のタスク構造を読み取りやすくする操作は，正解率の面ではほぼ無代償である（→ [§5.2](#52-正解率はほとんど動かない)）．
3. **しかし，読み取りやすさの増加に，答えの生成での利用は伴っていない**——署名で整合した群（proposal）では答えが第16層に頼る度合いがむしろ2割前後下がり（ラベルを並べ替えた群では下がらない），読める構造は第16層で答えを動かす方向にも集中しない．ただし一次近似の測定であり，言えるのは「まったく使っていない」ではなく「頼る度合いが下がった」までである（→ [§5.3](#53-読み取りやすさの増加に答えの生成での利用は伴っていない)）．

**貢献．** 線形に読み取れる構造は，明示的な損失でほぼ無代償に作り込んでも，モデルがそれを使うことを意味しない——「読み取れること」と「答えの生成に使われること」は一致しない．これを，既にある性質を除いて示した先行研究（Elazar ら）に対し，性質を足して構成的に示す（→ [§6](#6-結論と貢献)）．

**限界．** 結果はすべて一点についてのものである（整合の強さ $\lambda = 0.1$，第16層，単一モデル，単一データセット，1エポック）．「署名」が解き方の正しい形式化かは検証していない（→ [§7](#7-限界)）．

**表現の頑健性は，比で見るか距離で見るかで向きが変わる．** 出発点だった「整合は表現の頑健性を高めるか」を，画像を加工したときの第16層の表現の動きで測った．測る量は，同じ質問に別の画像を与えたときの動きに対する比である．この測定にだけ乱数種を2つ足し，結果を見る前に決めた5本で読んだ（→ [§8.1](#81-表現の頑健性の向きを決める乱数種を足す)）．署名で整合した群の比は，整合前より小さく（−4.82pt [−7.87, −1.77]），ラベルを並べ替えた群より小さい（−11.03pt，区間は 0 を含まない）．並べ替えた群の比は，整合前より大きい（+6.21pt，区間は 0 を含まない）．しかし比の分母は群ごとに違い，距離そのもので見れば，署名で整合した群のほうが加工でよく動く（区間は 0 を含まない）．画像を差し替えたときの動きに比べて加工による動きは小さくなったが，安定性は，比で見るか距離で見るかに依る．最終層の比と答えでは，幾何的な加工について3群の差は見られない（→ [§A.6](#a6-表現の頑健性画像を加工したときの表現の動き)）．

**掛ける場所と強さを変えた測定を進めている．** 整合の強さを $\lambda = 0.03$〜$1.0$ に振ると（乱数種1つ），読み取り精度は強さとともに上がり続け，正解率はほとんど動かない．答えが整合した位置に頼る度合い（相対感度）は，どの強さでも整合前より低いが，強さとともに単調には下がらない（→ [§8.4](#84-及ぶ範囲を広げる整合の強さ別のモデルとデータ)）．答えが各層・各位置にどれだけ頼るかを測ると，第16層で質問文の最後のトークンからプロンプトの末尾までの6位置のうち，最も頼られていたのは，整合した末尾の位置だった．そこで，6位置すべてに掛け直す学習を進めている（→ [§8.5](#85-掛ける場所と方向を変えても構造は使われないか)）．

**[§5](#5-主結果) までの本文は，補助的な検証を読まなくても筋が通る．** プローブの当てはめ方，組成への波及，正解率が上がらない理由の層別，「利用が伴っていない」をどう測ったか，層を変えた試走，画像を加工したときの表現の動きは [付録A](#付録a補助的な検証) にまとめた．

## 1. 背景

### 1.1 出力が同じでも，内部表現が同じとは限らない

VLM の頑健性は通例，入力を少し変えても答えが変わらないこと——出力の頑健性——で測られてきた．しかし Wani らは，**答えが変わらないまま内部表現が大きく変化する**ことを示した．画像に，意味を変えない加工（平行移動・拡大縮小・回転や，画像への文字の重ね書き）を施すと，答えをほとんど保ったまま内部表現は変化する（集計は答えが変わらなかった問に限っていない）．幾何的な加工での変化量は小さいが，文字の重ね書きでは，無関係な画像を入れたときの変化量に迫ることがある（最も小さいモデルで最も顕著である）．

つまり，**出力の頑健性は，表現の頑健性を含意しない**——出力を見ているだけでは，内部で何が起きているかは分からない．著者らは対処法を示していない．方向として挙げるのは，同じ入力を拡張したときの埋め込みの動きを罰する学習目的などで，今後の課題としている．

### 1.2 本研究の問い

Wani らが見ているのは「同じ入力を揺らしたときの変化」である．**別々の質問どうしの内部表現が互いに近いかどうかは，そこでは問われていない**——本研究はそこから入る．

**中心の問いは一つである——タスク構造（署名）を内部表現に明示的に作り込んだとき，その構造は答えの生成に使われるか．** 使われる度合いは，答えがその表現にどれだけ依存するかで測る（→ [§5.3](#53-読み取りやすさの増加に答えの生成での利用は伴っていない)）．作り込めたか（署名を線形に読み取れる度合い，→ [§5.1](#51-署名の読み取りやすさは大きく上がる)）と，その代償（正解率，→ [§5.2](#52-正解率はほとんど動かない)）は，この問いの前提として測る．正解率を上げることは目的ではない——上がらないこと自体が，理由とともに測られた結果である．出発点だった表現の頑健性は，付録で測った（→ [§A.6](#a6-表現の頑健性画像を加工したときの表現の動き)）．

**発表では，中心の問いを，聴き手に分かる正解率の側から問う形で掲げる．** 正解率を上げることを目的としない点は，中心の問いと変わらない．人間は画像が加工されても，同じ手順を踏んで答えを導くと考えられる（本研究の見方で，検証していない）．GQA の functional program は，答えに至る推論の手順を書き下したものである（→ [§3.1](#31-タスク署名解き方を比べられる形にする)．原典は program を人間の手順とは呼ばない．ポスターは 2026-11-13 から，教授の指示で「人間が行う視覚的推論を計算可能な操作の列で表現したもの」と書き，これを著者の読みとする）．そこでポスター（2026-11-09）は，「答えに至る手順を視覚言語モデルの内部表現が獲得できれば，正解率は上がるか？」と問う．手法のキーアイデアは，その問いが前提とすること（内部表現が手順を獲得すること）を実現する手段として置く——手順が同じ質問どうしの内部表現を近づけ，違えば遠ざける．すると内部表現が手順ごとにまとまり，手順を見分けられる情報を持つ（この情報は，表現から署名を当てる線形分類器の正解率で測る．[§5.1](#51-署名の読み取りやすさは大きく上がる) で読み取り精度と呼ぶ量である）．これを手順の獲得とみなす（ポスター，2026-11-13）．手順の獲得は手法の狙いであって，それで正解率が上がるという期待は，[§3.3](#33-どこに掛けるか射影を挟まない中間層の一点) の「届きうる」の強さを越えない．結果として，正解率はほとんど変わらなかった（→ [§5.2](#52-正解率はほとんど動かない)）．

## 2. 目的と貢献

**することは一つである．** 署名が一致する質問どうしの内部表現を明示的に近づける項を，通常の学習に足す（→ [§3](#3-手法)）．整合の有無とラベルの意味だけを変えた三つの群を乱数種3つで学習し（計9回，→ [§4](#4-実験設定)），表現の側と出力の側の両方で測る（→ [§5](#5-主結果)）．

**貢献は，「読み取れること」と「使われること」を分けて示したことである．** 表現から性質が線形に読み取れること（デコード可能性）と，モデルがその性質を計算に使っていること（利用）は別である．この区別は probing という枠組みへの既知の批判であり（Belinkov による総覧がある），Elazar らは BERT で，既にある性質を除いてモデル自身の語予測への影響を見た．本研究は逆に，性質を明示的な損失で足す：署名を，正解率をほとんど損なわずに（[§5.2](#52-正解率はほとんど動かない)）線形に読み取れる形へ作り込んだうえで，それが答えの生成に使われるかを問う（[§5.3](#53-読み取りやすさの増加に答えの生成での利用は伴っていない)）．答えは，読み取りやすさの増加に利用は伴っていない，である——答えが第16層に頼る度合いは，むしろ2割前後下がる（一次近似の測定）．作り込んでもなお，読める量は使われる量を意味しない．

**先行例（傍証）．** 表現のレベルに手を入れて正解率を上げた前例が VLM にある——VLsI（Lee ら）は，大きい VLM が層を追って推論を進めていく様子を，各層の特徴を自然言語へ写して小さい VLM に教え，正解率を上げた．これを「途中の表現まで教えるほうが，学習に届く手がかりは多い」という前提の傍証として援用するにとどめ，中核の主張の支柱には据えない．あちらは外部の大きいモデルを教師とする蒸留であり，本研究は教師を持たない同一モデル内の自己整合で，表現そのものを直接近づけるからである．しかも同論文の付録Dでは，言語の出力層を介さず中間層を直接合わせた蒸留は最終層だけの蒸留より低いので，傍証が効くのは言語の出力層を介す形に限られる．

## 3. 手法

### 3.1 タスク署名——解き方を，比べられる形にする

GQA は画像への質問応答データセットである．各サンプルは画像・質問文・答えに加えて **functional program** を持つ．program は答えに至る道筋を段階ごとに書き下したもので，各ステップが演算子と引数と依存先を持つ．“Who is wearing the dress?” なら

| 順 | 演算子 | 引数 | 依存 |
| --- | --- | --- | --- |
| 0 | `select` | `dress` | — |
| 1 | `relate` | `person, wearing` | 0 |
| 2 | `query` | `name` | 1 |

——「ドレスを選び，それを着ている人物へ関係をたどり，その名前を答える」．**この program が付いていることが GQA を採用した理由**で，解き方が同じかどうかを人手を介さずに判定できる．

ここから演算子の系列だけを取り出したものをタスク署名（以下，署名）と呼ぶ．この例なら `select > relate > query` である．“What is the boy wearing?” も同じ署名なので同じタスク，“What color is the cup?” は `select > query` で別タスクとなる．タスク類似性は連続量ではなく署名が一致するか否かの二値とし，一致する対を**正例対**（整合損失が近づける対）とする．

以降，「解き方が同じ」はすべて「署名が一致する」の意味で用い，測定はすべて署名について行う．**署名が解き方の正しい形式化かどうかは，本研究では検証していない**（→ [§7](#7-限界)）．

**引数を捨てるのは意図的である．** 引数まで一致を求めると，正例対がほとんど同じ質問になってしまい，表現が近いのは当たり前になる．捨てたことで，同じ署名の質問どうしでも答えは違う（`select > relate > query` の答えは “women” だったり “tie” だったりする）．

**注意すべき交絡がある．** GQA の質問文はこの program と同じ質問パターンから自動生成されているので，質問文の言い回し——どの語が現れ，どの2語が隣り合うか——と署名は，作りからして相関している．極端な場合には，演算子の名前がそのまま質問文に現れる（[§4.1](#41-モデルとデータ) の報告用データでは，現れる 118 種の演算子のうち 10 種が該当する——`and`・`or`・`common` など）．質問文を読むだけで分かってしまう分は，差し引かなければならない（→ [§5.1](#51-署名の読み取りやすさは大きく上がる)）．

### 3.2 整合損失

バッチ $B$ 件について，モデルが答えを出す途中で保持している内部表現を $h_1,\dots,h_B \in \mathbb{R}^{H}$（以下，単に**表現**と書く．質問文の言い回しを指すことはない），その署名ラベルを $y_1,\dots,y_B$ とする．正規化した表現を $z_i = h_i / \lVert h_i \rVert_2$，そのコサイン類似度を $s_{ij} = z_i^{\top} z_j$ とし，質問 $i$ の正例の集合を $P(i) = \lbrace j \neq i \mid y_j = y_i \rbrace$ と書く．**整合損失**は署名をラベルとする supervised contrastive loss（SupCon——同じラベルの表現どうしを近づけ，違うラベルの表現どうしを遠ざける損失）であり，

$$
\mathcal{L}_{\mathrm{align}} = \frac{1}{|\mathcal{I}|}\sum_{i \in \mathcal{I}} \left[ \log \sum_{j \neq i} \exp\left(\frac{s_{ij}}{\tau}\right) - \frac{1}{|P(i)|} \sum_{p \in P(i)} \frac{s_{ip}}{\tau} \right],
\qquad
\mathcal{I} = \lbrace i \mid P(i) \neq \varnothing \rbrace
$$

第1項がバッチ全員との近さ，第2項が同署名との近さで，**この差を小さくすることが，同署名だけを相対的に近づけることにあたる．** 外側の和は，バッチの全件ではなく $\mathcal{I}$ について取る．この $\mathcal{I}$ から外れるのは，同じ署名を持つ質問が同じバッチに1件も無い質問である——近づける先が無いので $P(i)$ が空になり，第2項が 0 で割ることになる．ただし本研究のバッチは 16 種の署名から2件ずつ引くので（→ [§4.1](#41-モデルとデータ)），外れる質問は生じず，各質問の正例はバッチにちょうど1件である．温度 $\tau$ は，学習可能なパラメタとし初期値を 0.07 とする（SupCon の原典は固定の温度で，この形はこちらで決めた）．

全体の目的関数は，**整合の強さ** $\lambda$ を 0.1 として

$$
\mathcal{L} = \mathcal{L}_{\mathrm{LM}} + \lambda \mathcal{L}_{\mathrm{align}}
$$

とする．このうち $\mathcal{L}_{\mathrm{LM}}$ は**答えのトークンにのみ**掛かる通常の交差エントロピーである．

### 3.3 どこに掛けるか——射影を挟まない中間層の一点

整合損失は，生の表現に直接掛ける．SupCon の原論文は，表現を低次元へ写す小さなネットワーク（射影 head）の出力の上で損失を計算している．本研究があえて射影を挟まないのは，**挟むと仮説が反証不能になる**からである——学習可能な射影があれば，表現をまったく変えずとも射影の側を変えるだけで損失を下げられてしまう．

**掛ける先は，第16層（全32層の中間）で，質問を読み終えて答えを書き出す直前の位置にあるベクトルそのものである**（次元は $H = 960$）．

**この位置はプロンプトの末尾で，画像と質問文のすべてを参照できる**——言語側は自己回帰なので，各トークンは自分より前の位置しか見られない（**causal attention**）．質問文のあとに続く定型の数トークンも同じく全体を参照できるが，答えの先頭トークンを選ぶスコアが出るのはこの末尾である．整合がここに載せた構造が答えの決まり方に届きうるのは，そのためである．

**整合損失が測るのは，この1本のベクトルだけである．** ただし，損失を下げる学習は全パラメタに及ぶ．重みは全位置で共有され，このベクトルは注意を通じて前の位置の第1〜15層の状態にも依るので，画像と質問文の位置の表現も変わりうる．それらの位置は損失に縛られず，残る16層は注意でそれらを読めるので，このベクトルの情報が損なわれても，後段は他の位置から読み直せる．ほかの位置の表現が変わったか，後段が読み直したかは測っていない（→ [§8.5](#85-掛ける場所と方向を変えても構造は使われないか)）．層も位置も，ここ以外は試していない（→ [§7](#7-限界)）．

**射影を外しても，構造が答えの生成に関与しない余地は残る．** 学習可能な射影が無い以上，損失を下げるには第16層のベクトルそのものが変わるほかなく，実際に変わった（→ [§4.4](#44-操作の確認整合は表現をどう変えたか)）．しかし，この位置が必ず読まれることは，そこに載った構造まで読まれることを意味しない．960 次元のベクトルから答えのスコアへの写像は多対一であり，動かしても出力がほとんど変わらない方向が残る——署名の構造がそこに載れば，表現には載るが答えの生成には関与しない．射影を外して防げたのは，表現を変えずに損失を下げる道だけである．どちらが起きたかを測ったのが [§5.3](#53-読み取りやすさの増加に答えの生成での利用は伴っていない)（測定方法は [§A.4](#a4-利用が伴っていないをどう測ったか三段の測定)）である．

**構造が答えの生成に関与しない道は，二つある．** 後段が他の位置から読み直す道（位置の道）と，構造が答えを動かさない方向に載る道（方向の道）である．二つは，答えが構造をあまり読まないという点で同じで，違うのは，読まれにくい所が位置かベクトルの中の方向かである．**どちらも，整合で作った構造が答えを良くしないときに通りうる．** 構造が答えを良くする（$\mathcal{L}_{\mathrm{LM}}$ を下げる）なら，$\mathcal{L}_{\mathrm{LM}}$ の勾配は，後段がこのベクトルを読むようにも，構造が答えを動かす方向に載るようにも学習を進めうる．良くしないなら事情が違う．整合損失はどの方向で表現をまとめるかを決めないので，答えを動かす方向でまとめれば，良くしない構造で答えが変わるので $\mathcal{L}_{\mathrm{LM}}$ が上がり，動かさない方向でまとめれば上がらない．答えを動かす方向でまとめても，後段がこのベクトルを読む度合いを下げて他の位置から読み直せば，同じく上がらずに済む．二つの損失をともに下げる学習がこれらの道へ進みうるというのは，損失の形からの推論であり，確かめていない．

## 4. 実験設定

### 4.1 モデルとデータ

モデルは軽量な VLM **SmolVLM-500M-Instruct** を使う——計算資源の都合による．言語側は32層で，表現の次元は 960 である．

学習は GQA の `train_balanced` で1エポック．943,000 問のうち，同署名の相手がいない 884 問は正例対を組めないので除く．バッチは16 署名を無作為に選び，各署名から2件ずつ引いて $B = 32$ 件とする．1エポックは，残る 942,116 問を 32 件ずつ引き切る回数（端数は切り捨てて 29,441 バッチ）と定める——署名を単位に引き直すので，各問がちょうど一度ずつ出るわけではない．引くのは問の数によらず署名を均等にであり，各署名は約 598 問ずつ（29,441 バッチ × 16 署名 × 2 問 ÷ 1,575 署名）引かれる．問の多い上位 10 署名（565,528 問）はここで頭打ちになるので，一度でも出る問は多くて約 38 万問（全体の約 41%）である．これは頭打ちを上位 10 署名にだけ当てた粗い上限で，実測ではない．11 位以下の署名ごとの問数は手元の記録に無く，その中に約 598 問を超えるものがあれば，実際の数はさらに少ない（10 位は 16,153 問）．学習率 $10^{-5}$，勾配ノルムは 1.0 で打ち切る．**乱数種 42・43・44 の3つで，3群 × 3乱数種 ＝ 9回の学習を行った**（1回 約2時間53分，通しで約26時間）．署名でまとめたバッチを作るのは学習時だけで，評価は自然な分布のまま行う．

報告は `testdev_balanced` 12,578 問で行う（以下**報告用データ**）．GQA の `test` 分割は答えが伏せて配布されていて手元で採点できず，`testdev` は GQA が答えを添えて配り，開発中の評価に勧めている分割だからである（本研究は学習に使っていない）．**学習・検証・報告の3分割は，質問 ID も画像 ID も完全に排他である**——報告に使う 398 枚の画像は，学習中に一度も現れない．

### 4.2 三つの群

**proposal が「baseline と違い，かつ ablation とも違う」ことによって初めて，差を生んだのがラベルの意味であると言える．** どちらか一方だけでは，対照学習という形式そのものの効果と区別がつかない．

1. **baseline**：整合の強さ $\lambda = 0$．整合損失を掛けない．
2. **proposal**：ラベル $y_i$ を署名とする．
3. **ablation**：強さ $\lambda$ も損失の形も同じまま，バッチの中でラベル $y_i$ を無作為に並べ替える．通常の ablation のように構成要素を取り除くのではなく，ラベルの意味を取り除く群である．ラベルを作り直すのではなく並べ替えるので，ラベルの分布と正例対の数は厳密に保たれ，正例対の定義だけが無意味になる．

**ablation は表現を壊すために置く群ではない．** 変えるのはラベルの意味だけである——表現を壊す群を置いても，署名ラベルの効果とモデルを損なった効果とが混ざり，対照にならない．ただし実際には，ablation の表現はほぼ同じ向きに集まった（→ [§4.4](#44-操作の確認整合は表現をどう変えたか)）．それでも表現から署名を線形に読み取れる度合いは baseline とほぼ変わらないので，対照にはなっている（→ [§5.1](#51-署名の読み取りやすさは大きく上がる)）．

**この対照が答えるのは「ラベルに意味が要るか」までである．** 並べ替えたラベルは意味を持たないので，proposal との差は意味のあるラベルが要ることを示す．ただし並べ替えたラベルは質問と無関係なので，整合損失は，並べ替えについての期待値では，どの対の類似度も等しいときの値より下がらない．ablation はすべての表現を一つの向きに集めてこの値に着き，表現は分離しなかった（→ [§4.4](#44-操作の確認整合は表現をどう変えたか)）．したがってこの差は，表現がラベルで分離したか否かの差でもあり，表現を分離させる意味のあるラベルなら，署名でなくても同じ効果が出うる．答えの型（yes/no か自由回答か）のような別の意味のあるラベルで整合しても同じ効果が出るなら，主結果は署名についてではなく，意味のあるラベル一般についてのものになる．分けるには，そのラベルで学習し直すほかない（→ [§8.3](#83-答えが署名に固有かを確かめる別のラベルで整合する)）．

### 4.3 乱数種3つの，まとめ方

群ごとの数値は3つの乱数種の平均（標本数 $n = 3$）で報告し，ばらつきが読みに効くところには標準偏差を添える．

**群間の比較には，乱数種を対にした $t$ 検定（対応のある $t$ 検定．paired $t$-test）を用いる．** 対にするのは，同じ乱数種の3群が同じ順序で同じデータを見るからである——乱数種ごとに引き算すれば，初期化とデータ順序の効果が相殺される．乱数種 $i$ での群 $A$ の値を $x_i^{A}$ と書き，差 $d_i = x_i^{A} - x_i^{B}$ の $n$ 個について平均 $\bar{d}$ と標準偏差 $s_d$ を取る．報告するのは検定の $p$ 値ではなく，同じ枠組みが与える差の 95% 信頼区間である：

$$
\bar{d} \pm t_{n-1, 0.975} \frac{s_d}{\sqrt{n}},
\qquad
t_{2, 0.975} = 4.303
$$

$s_d/\sqrt{n}$ は $\bar{d}$ 自体の揺れ（標準誤差）で，係数 $t_{n-1, 0.975}$ は自由度 $n-1$ の $t$ 分布の 97.5% 点である．**標本が少ないほど大きくなる**——標本 $n = 3$ での 4.303 は，標本が十分あるときの 1.96 の2倍以上ある．

区間が 0 を含まないなら，差の向きは手元のデータで決められる．**含むなら，「差が無い」ことが示されたのではなく，向きを決められないというだけである．** 標本が3つなので区間は広く，そこから読める上限も緩い．

**同じ設定でも，乱数種を変えれば結果は変わる．** その変わる幅を，設定を変えていない baseline の3本だけからも測っておく．群間の差がこの幅の内側にあるなら，設定の違いによる差なのか，乱数種の違いによる差なのかを区別できない．

### 4.4 操作の確認——整合は表現をどう変えたか

主結果を読む前に，整合損失が下がり，表現がどう変わったかを確かめる．**proposal と ablation の値は操作の確認であって，仮説の支持証拠ではない**——ここで動く量は，整合損失が直接小さくしようとしている量そのものだからである．baseline の値だけは事情が違う．整合が何も掛かっていない群なので，こちらが動かした量ではなく，整合前の幾何そのものの記述である．

類似度と分離度は，報告用データから抜いた 4,000 件で測る（表の損失2行は，報告用データ全体をバッチごとに測って平均したものである）．署名が一致する対の集合を $\mathcal{P} = \lbrace (i,j) \mid i \neq j,\ y_i = y_j \rbrace$，一致しない対の集合を $\mathcal{N}$ と書き，[§3.2](#32-整合損失) のコサイン類似度 $s_{ij}$ をそれぞれで平均したものを**同署名の類似度**・**異署名の類似度**と呼ぶ．**分離度** $\delta$ はその差を，両集合の標準偏差を自由度で重み付けして合わせた $\sigma$（pooled standard deviation）で割ったものである（Cohen's d）：

$$
\bar{s}_{\mathcal{P}} = \frac{1}{|\mathcal{P}|}\sum_{(i,j) \in \mathcal{P}} s_{ij},
\qquad
\bar{s}_{\mathcal{N}} = \frac{1}{|\mathcal{N}|}\sum_{(i,j) \in \mathcal{N}} s_{ij},
\qquad
\delta = \frac{\bar{s}_{\mathcal{P}} - \bar{s}_{\mathcal{N}}}{\sigma}
$$

$\delta = 1$ なら「標準偏差1つ分だけ離れている」と読む．標準偏差 $\sigma$ で割るのは，類似度そのものの大きさに左右されずに群を比べるためである．

| 9回の学習が残した表現（平均 ± 標準偏差） | baseline | proposal | ablation |
| --- | --- | --- | --- |
| 同署名の類似度 $\bar{s}_{\mathcal{P}}$ | 0.9448 ± 0.0076 | 0.7451 ± 0.0047 | 0.9952 ± 0.0003 |
| 異署名の類似度 $\bar{s}_{\mathcal{N}}$ | 0.9183 ± 0.0100 | 0.2247 ± 0.0096 | 0.9944 ± 0.0004 |
| **分離度 $\delta$** | **0.816 ± 0.080** | **2.378 ± 0.117** | **0.451 ± 0.078** |
| 整合損失 $\mathcal{L}_{\mathrm{align}}$ | — | 2.1162 ± 0.0591 | 3.4338 ± 0.0001 |
| 言語モデル損失 $\mathcal{L}_{\mathrm{LM}}$ | 0.658 ± 0.009 | 0.652 ± 0.002 | 0.662 ± 0.003 |

**proposal の分離度は baseline の 2.9 倍で，3つの乱数種でほぼ完全に再現する**（標準偏差は平均の5%）．ablation では上がらない．

**ただし proposal は，同署名を近づけたのではない．** 同署名の類似度も下がっており，異署名の類似度がそれ以上に下がった結果として分離度が上がっている．ablation は逆に，同署名・異署名を問わず類似度が 0.99 を超え，すべての表現がほぼ同じ向きに集まった．

**その集まり方は，ablation のラベルに情報が無いことの裏づけになる．** 全ベクトルが同じ向きに揃えばどの対も $s_{ij} = 1$ になり，[§3.2](#32-整合損失) の式は $\log\bigl((B-1)e^{1/\tau}\bigr) - 1/\tau = \log(B-1)$ となる——温度 $\tau$ が打ち消し合うので，その値がいくつであっても整合損失はこの値である．本研究の $B = 32$ なら $\log 31 = 3.4340$ で，ablation の3つの乱数種が到達した値（表の $3.4338 \pm 0.0001$）は，いずれもこれと小数第3位まで一致する．並べ替えられたラベルは質問と無関係なので，質問から作る表現をどう変えても同ラベルだけを近づけることはできない——正例が無作為なので，損失は並べ替えについての期待値ではこの値を下回れない（Jensen の不等式による．どの対の類似度も等しいときに等号が成り立つ）．ablation は，すべてを同じ向きに潰すことでこの値に着いた．表の値がこれをわずかに下回るのは，報告用データの端数の2問だけのバッチ（損失は 0 になる）も平均に入るからである．

## 5. 主結果

3群 × 3乱数種の9回の学習による（まとめ方は [§4.3](#43-乱数種3つのまとめ方)）．

### 5.1 署名の読み取りやすさは，大きく上がる

表現から署名を当てる線形分類器（**プローブ**）を当てはめ，その正解率を**読み取り精度**と呼ぶ——高いほど，署名の情報がその表現から線形に取り出せる形で載っている．プローブが読むのは整合損失が触るベクトルそのもの（第16層の，質問を読み終えた位置）なので，読み取り精度の増分を整合の効果として読める．当てはめの手順と，表に並べた二つの対照の作り方は [§A.1](#a1-読み取りやすさの測定と二つの対照) にまとめた．

| 第16層の表現からの，署名の読み取り精度 | 通常の分割 | 書き出しを分離した分割 |
| --- | --- | --- |
| baseline（整合前） | 82.9% | 80.9% |
| **proposal（整合後）** | **95.9%** | **95.4%** |
| **整合の効果（proposal − baseline）** | **+13.0pt** | **+14.5pt** |
| ablation | 81.0% | 78.6% |
| （参照）言い回しプローブ（質問文だけを入力） | 69.7% | 66.1% |
| （参照）床（最も多い署名の割合） | 28.8% | 31.0% |

**増分の向きは，損失の定義から予想できる．** 同じラベルの表現を近づけ違うラベルを遠ざける損失は，そのラベルを線形に分離しやすくする——だから「上がった」こと自体は発見ではない．確定させるのは向きではなく，増分がラベルの意味に帰属し，質問文には帰属しないことである．

- **増分には，意味のあるラベルが要る（ablation）．** ablation では上がらない（81.0%，整合前と −1.9pt）——対照学習という形式そのものではなく，ラベルの意味が差を生んでいる．そのラベルが署名である必要があるかは，この対照では分からない（→ [§8.3](#83-答えが署名に固有かを確かめる別のラベルで整合する)）．しかも ablation は分離度が baseline より低い（0.451 対 0.816）のに読み取り精度は baseline のままで，表現どうしの距離と，そこから線形に取り出せる情報の量は別の量である．
- **増分は，質問文からは説明できない（言い回しプローブ）．** 質問文の言い回しだけを入力にした同じ分類器は 69.7% にとどまり，整合後の表現はそこを +26.2pt 上回る（書き出しを分離した分割では +29.3pt）．
- **増分は，質問の書き出しを未見にしても保たれる（書き出しを分離した分割）．** +14.5pt と，差はむしろ広がる．

**整合前も署名は読み取れる——ただし幾何として近いわけではない．** baseline の 82.9% は床の 28.8% から遠く，言い回しプローブも +13.2pt 上回る．一方で同署名の類似度 0.945 と異署名の 0.918 の差はわずかで，分離度は 0.82 にとどまる（→ [§4.4](#44-操作の確認整合は表現をどう変えたか)）．「同じ解き方で解ける質問どうしは近いか」への答えは，わずかに近いだけだが，署名の情報は線形に取り出せる，である．

この効果は署名そのものにとどまらず，署名を組み立てている演算子の組成にまで及ぶ（→ [§A.2](#a2-演算子の組成も読み取れるようになる)）．

### 5.2 正解率は，ほとんど動かない

各ステップで最も確からしい語を選ばせて（貪欲デコード）答えを作らせ，GQA 公式の評価器で採点する．**正解率**は，そこで正解した問の割合である（12,578 問すべて採点，採点漏れ0問）．群間で比べられる損失は $\mathcal{L}_{\mathrm{LM}}$ だけである——全体の $\mathcal{L}$ には整合する群にのみ補助項が乗るので，同じ量ではない．

| 正解率（`testdev_balanced`） | baseline | proposal | ablation |
| --- | --- | --- | --- |
| 乱数種 42 | 52.98 | 53.37 | 53.42 |
| 乱数種 43 | 53.53 | 53.84 | 53.85 |
| 乱数種 44 | 54.12 | 53.25 | 53.43 |
| **平均 ± 標準偏差** | **53.54 ± 0.57** | **53.49 ± 0.31** | **53.57 ± 0.25** |

**どの群間の差も，区間は 0 を跨ぐ．** proposal の baseline に対する差は乱数種ごとに $+0.39 / +0.31 / -0.87$，したがって平均は $\bar{d} = -0.06$，標準偏差は $s_d = 0.706$，標準誤差は $s_d/\sqrt{3} = 0.407$ で，[§4.3](#43-乱数種3つのまとめ方) の区間は

$$
-0.06 \pm 4.303 \times 0.407 = -0.06 \pm 1.75 = [-1.81, +1.70]
$$

乱数種ごとの符号は揃わない．差の平均は，baseline を乱数種だけ変えて3本走らせたときのばらつき（標準偏差 0.57，幅 1.14pt）の内側でもある．ablation を絡めた残り2組も同様に 0 を跨ぐ．

**区間が 0 を跨いでも「差は無い」とは言わない．言えるのは上限である——低下は最大でも 1.81pt，53.5 に対して3%強にとどまる．** $\mathcal{L}_{\mathrm{LM}}$ も，baseline との差は乱数種ごとのばらつきより小さい（→ [§4.4](#44-操作の確認整合は表現をどう変えたか)．proposal と ablation の差 −0.010 だけは区間が 0 を含まない）．

**正解率が上がらない理由は，別に測った**（→ [§A.3](#a3-正解率が上がらない理由頻度層別と正誤で分けたプローブ)）——誤答した質問でも，第16層から署名は高い精度で読み取れる．誤りが署名より後の段階で起きている，というのはそこから立つ説明の候補であり，確かめていない．

### 5.3 読み取りやすさの増加に，答えの生成での利用は伴っていない

[§5.1](#51-署名の読み取りやすさは大きく上がる) は「読み取れる」ことしか言わない．**モデルがその署名を答えの生成に使っているか**は別の問いである——高い精度で読める性質（句境界）が，除いても語予測を下げない例が知られている（非マスクの BERT．Elazar ら）．そこで，署名が表現のどこに載っているか，そして答えがその位置にどれだけ頼っているかを測った（測定方法の詳細は [§A.4](#a4-利用が伴っていないをどう測ったか三段の測定)）．

- **答えは，整合が触った第16層に，以前より頼らなくなる．** 第16層を動かしたとき答えがどれだけ動くかを両端の大きさで割った無次元量を**相対感度**と呼ぶ．出力層が読む方向を 8・32・128 本取った3通りのいずれでも，proposal の相対感度は baseline から 28.0／21.6／18.0% 下がり，3つの乱数種で向きが揃う．ただし区間は，8・32 本で 0 を含まず，128 本で含む（→ [§A.4](#a4-利用が伴っていないをどう測ったか三段の測定)）．ラベルを並べ替えた群（ablation）では下がらない（−4.3／−0.5／+0.4%）ので，この低下には意味のあるラベルが要る．
- **読める構造は，第16層で答えを動かす方向にも集中していない．** 整合前は，第16層で答えを動かす8方向の中で署名が，無作為に取った8方向の中でより 2.82pt よく読めたのに対し，整合後はその差が無い．
- **ただし，これは一次近似の測定である．** 相対感度は第16層のまわりで線形化した一次の量であり，非線形の経路まで否定しない．下がったのは2割前後でありゼロではない．言えるのは「まったく使っていない」ではなく，「頼る度合いが下がった」までである．

**したがって [§5.1](#51-署名の読み取りやすさは大きく上がる) の +13.0pt は，表現の形式が組み替わったことを意味するのであって，モデルが署名を使うようになったことを意味しない．** 強さや層を変えて同じ数字を精密にしても，精密になるのはこの範囲の中である．

## 6. 結論と貢献

**三つの主結果を一文で束ねる．** 署名で表現を整合させると，第16層で署名が線形にずっと読み取りやすくなり（+13.0pt），そのあいだ正解率はほとんど動かない（低下は最大でも 1.81pt）が，答えが第16層に頼る度合いはむしろ下がり（2割前後），読み取りやすさの増加に利用は伴っていない．

**貢献は，「読み取れること」と「使われること」を分けて示したことである．** 表現から性質が線形に読み取れることは，モデルがその性質を計算に使っていることを意味しない——この区別自体は probing への既知の批判だが，Elazar らは既にある性質を除いてモデル自身の語予測への影響を見たのに対し，本研究は性質を明示的な損失で足す．ほぼ無代償で線形に読み取れる形へ作り込んでもなお，答えが第16層に頼る度合いは上がらず，むしろ下がる（一次近似で2割前後）．プローブの読み取り精度が上がったことを「モデルがそのタスク構造を理解した／使うようになった」と読んではならない，ということを，構成的な例で示す．

**この研究から言えないこと．**

- モデルが署名を使うようになった，署名を理解した，新しい推論能力を獲得した——いずれも言えない．増えたのは表現の形式である．
- **VLM 一般**について言えることではない．単一モデル・単一データセット・単一層・一つの強さでの結果である（→ [§7](#7-限界)）．
- 「署名」が解き方の正しい形式化だとは**示していない**（→ [§7](#7-限界)）．
- 整合が入力の揺らぎに対する表現の**頑健性を高めた**とは言えない——これは本研究の出発点だった問いである．乱数種を5つに増やして測ると，画像を差し替えたときの動きに比べて，加工による動きは整合前より小さくなった（判定に使う比で −4.82pt，区間は 0 を含まない．ラベルを並べ替えた群では大きい）．しかし距離そのものでは，第16層で proposal のほうがよく動く（区間は 0 を含まない）．安定性は，比で見るか距離で見るかに依る（→ [§A.6](#a6-表現の頑健性画像を加工したときの表現の動き)）．

## 7. 限界

**主結果は，設計の選択肢を一組に固定して得たものである．** $\lambda = 0.1$，第16層，質問を読み終えた位置，温度 $\tau$ の初期値 0.07 は，9回の学習すべてで同じ値である．[§5](#5-主結果) の結果は「この一点における整合の効果」であって，「整合という手法の最良の姿」ではない．層だけは第8層・第24層で乱数種1つの試走があるが，1つでは区間を作れない（→ [§A.5](#a5-整合する層を変えた試走乱数種1つ)）．[§5.1](#51-署名の読み取りやすさは大きく上がる) の読み取り精度の利得と，[§5.2](#52-正解率はほとんど動かない) の向きの決まらない正解率の差（−0.06pt，区間 [−1.81, +1.70]）が $\lambda$ でどう釣り合うかは未測定である（→ [§8.4](#84-及ぶ範囲を広げる整合の強さ別のモデルとデータ)）．

**答えが署名に固有だとは，まだ示していない．** [§4.2](#42-三つの群) の ablation が示すのは，並べ替えた無意味なラベルでは同じことが起きない，までである．別の意味のあるラベルで整合しても同じ増分が出るなら，主結果は「署名で整合させると」ではなく「意味のあるラベルで整合させると」と書き直さなければならない（→ [§8.3](#83-答えが署名に固有かを確かめる別のラベルで整合する)）．

**署名が解き方の形式化として最良だとは示していない．** GQA 公式の一貫性（consistency）指標は含意関係にある質問対に互いに矛盾しない答えを要求するが，`val_balanced` の 20,867 対のうち 52.1% は署名が異なる——本研究の損失が引き離す対に対して，公式指標は矛盾しない答えを求めている．ただし，この食い違いは署名の誤りではなく，二つが別のものを捉えていることの現れである（GQA の含意関係は同じ場面についての問を結び，署名は解き方を区別する．事実，署名が異なる対の 44.2% は yes/no 型の問と自由回答型の問を組にしている——署名が一致する対では 0.0%）．それでも，解き方を演算子の系列で代表させることが最良かどうかは，別の形式化と比べていない以上，未検証である．

**表現の頑健性の判定は，乱数種5つと一つの比の作り方に依る．** 整合前との差の大きさは，対照が同じ質問に別の画像を付けたものである四つの比の作り方のあいだでも約2倍変わる（−2.2〜−4.8pt）．対照を別の問にした残る二つの作り方では −0.75pt と −0.49pt である．向きは比の作り方ではどれも同じで，区間は対照を同署名の別の問にした比を除いて 0 を含まないが，距離そのものでは向きが逆になる．Wani らと同じ形で報告した Cohen's d は，群ごとに対照の広がりが違うので，群の比較には使えない（→ [§A.6](#a6-表現の頑健性画像を加工したときの表現の動き)）．

**「利用が伴っていない」は，第16層について，一次近似で測った．** [§5.3](#53-読み取りやすさの増加に答えの生成での利用は伴っていない) の相対感度は整合が触った位置のものであり，別の層で整合したときに同じことが起きるかは測っていない．整合が触る位置は答えの先頭トークンがそこから選ばれる位置なので，構造が使われているという仮説には最も有利な位置である——そこで利用が伴わないなら，経路がより間接的な位置で伴う理由は見当たらないが，測ってはいない．層については，第16層が最も有利だとは言えないので，この推論は使えない（→ [§8.4](#84-及ぶ範囲を広げる整合の強さ別のモデルとデータ)）．ほかの層と位置に答えがどれだけ依存しているかも測っていない（→ [§8.5](#85-掛ける場所と方向を変えても構造は使われないか)）．相対感度は一次の量なので，非線形の経路を通じた利用は否定しない．それを確かめる測定は計画に置いておらず，§8.5 の測定も一次の相対感度で読むので，この留保はそこにも及ぶ．

### 8.1 表現の頑健性の向きを決める——乱数種を足す

**[§A.6](#a6-表現の頑健性画像を加工したときの表現の動き) の測定は，乱数種3つでは整合前との差の向きを決めなかった．** 判定に使う比の差は3つの乱数種すべてで負だった（−4.30／−9.06／−3.62pt）が，区間は 0 を含んだ．問は 12,578 あるので，問の側の揺れは区間にほとんど効かない．区間を広げていたのは，乱数種のあいだの揺れである．したがって，保存済みの距離をどう読み直しても向きは決まらず，決めるには，乱数種を足して学習し直すほかなかった．

**足す本数は，結果を見る前に決めた．** 区間が 0 を外れるまで足しては止める，というやり方では，区間の意味が崩れる．乱数種 45・46 を足し，5本で報告する．3本の差の乱数種間の標準偏差（判定に使う比で 2.96pt）が保たれるなら，5本の区間の半幅は $2.776 \times 2.96 / \sqrt{5} = 3.7$pt になり，3本の差の平均 5.7pt を下回る（係数は自由度 4 の $t$ 分布の 97.5% 点）．ただしこの標準偏差は3本から見積もったもので粗く，しかも baseline の乱数種 43 だけが大きく外れていた（18.8% 対 13.9%・14.3%）ので，向きが決まることは保証されていなかった．

**走らせたのは，3群 × 2乱数種の学習と，その重みでの同じ測定である．** 学習は1回 約2時間53分で計 17時間18分，測定は1回 約32分で計 3時間13分かかった．3群すべてを回したのは，ablation との差も同じ5本で出すためである．追加の2本は頑健性の判定にだけ使い，[§5](#5-主結果) の主結果は3本のまま報告する．

**読みは，[§A.6](#a6-表現の頑健性画像を加工したときの表現の動き) の判定の表を [§4.3](#43-乱数種3つのまとめ方) の規則と合わせ，比の分母が群ごとに違うことを織り込んだものである．** 判定に使う比だけでは，加工で動きにくくなったのか，画像を差し替えたときの動きが大きくなったのかを分けられない（→ [§A.6](#a6-表現の頑健性画像を加工したときの表現の動き)）．そこで比と並べて，距離そのものの差も同じ5本で出し，比の作り方を変えた読みも並べる．

### 8.2 稀な署名を，表現の側で測る

**[§A.3](#a3-正解率が上がらない理由頻度層別と正誤で分けたプローブ) の答えを，半分から全体にする．** 学習にほとんど現れない署名で正解率が下がる傾向（1–10 の層で −2.50pt，ただし区間は 0 を跨ぐ）は出力の側の測定であり，同じ層別を表現の側では行っていない．[§A.3](#a3-正解率が上がらない理由頻度層別と正誤で分けたプローブ) と同じ五つの層の上で [§5.1](#51-署名の読み取りやすさは大きく上がる) のプローブを当て直せば，二択が分かれる．

- **表現も組み替わっていない**——稀な署名では，同じ署名の質問が同じバッチに揃うことが少なく，整合損失がほとんど掛からなかったことになる．このとき正解率の低下は，整合が届かなかった場所で起きた副作用である．
- **表現は組み替わっているが，出力に届かない**——読み取り精度は稀な層でも上がっているのに，正解率は下がる．このとき [§5.3](#53-読み取りやすさの増加に答えの生成での利用は伴っていない) の「利用が伴っていない」がここでも効いていることになる．

**この測定は，設計を何も変えない．** 保存済みの表現を層別に読み直すだけだからである．ただし層が細かくなるぶん，「10 問以上ある署名に限る」という条件が層ごとに掛かり直すので，どの頻度の層で読み取り精度を採点できるかを先に確かめる．

### 8.3 答えが署名に固有かを確かめる——別のラベルで整合する

**主結果は「署名で整合させると」で始まる．その「署名で」を支えているのは，いまのところ [§4.2](#42-三つの群) の ablation だけである**——並べ替えた無意味なラベルでは同じことが起きない，までしか言えない．

第4の群を足す．強さ $\lambda$ も損失の形も同じまま，ラベルを**答えの型**（yes/no か自由回答か）にする．署名はこれを厳密に細分する（解き方が同じなら答えの型も必ず同じで，`val_balanced` の含意対では例外が 0.0% である）ので，このラベルは，署名が持つ情報のうち最も粗い部分だけを取り出したものになる．

| 結果 | 意味 |
| --- | --- |
| 増分が出ない | **答えは署名に固有である．** 主結果はそのまま立つ |
| 増分の一部が出る | 出た分は，署名のうち答えの型で説明できる部分である．答えを「署名で整合させると」から「署名の粗い分割で整合させても」へ書き直す |
| 同じ増分が出る | 答えは署名についてではなく，**意味のあるラベル一般についてのもの**になる |

**この対照で最も効くのは，演算子を当てるプローブ（→ [§A.2](#a2-演算子の組成も読み取れるようになる)）である．** 答えの型は演算子の集合をほとんど決めないので，[§A.2](#a2-演算子の組成も読み取れるようになる) の +8.2pt がこの群でも出るなら，組成の所見は署名とは無関係だったことになる．

**同じ群で，表現の頑健性も測る（2026-11-18 に決めた）．** [§4.2](#42-三つの群) のとおり，proposal と ablation の差は表現がラベルで分離したか否かの差でもあるので，表現を分離させる意味のあるラベルなら，署名でなくても [§A.6](#a6-表現の頑健性画像を加工したときの表現の動き) と同じ結果が出うる．答えの型で表現が分離したかは，[§4.4](#44-操作の確認整合は表現をどう変えたか) の分離度を答えの型のラベルで測って確かめる．頑健性は §A.6 と同じ測定を，§A.6 と同じ乱数種5つ（42–46）で行い，判定に使う比と距離そのものを並べる．増分（読み取り精度と，演算子を当てるプローブ）は，[§5](#5-主結果) と同じく乱数種 42–44 の3本で読む．

| 5本での判定に使う比 | 意味 |
| --- | --- |
| 答えの型の群も baseline より小さく（区間が 0 を含まない），proposal との差の区間が 0 を含む | 比の低下は署名に固有ではなく，答えの型でも起きる |
| 答えの型の群は baseline より小さくならず，proposal がそれより小さい（区間が 0 を含まない） | 比の低下は署名に固有である |
| それ以外 | 署名に固有かは決められない．区間をそのまま報告する |

比の分母は群ごとに違うので（→ §A.6），どの行でも，安定性の増減は [§8.1](#81-表現の頑健性の向きを決める乱数種を足す) の規則で読む——比と距離そのものの向きが揃うときだけ書き，逆なら，比で見るか距離で見るかに依ると書く．

**要るもの．** 答えの型をラベルにして学習する実装（未実装）と，1回 約2時間53分の学習5回（計約14時間半）と，その重みでの頑健性の測定5回（1回 約32分，計約2時間40分）である．

### 8.4 及ぶ範囲を広げる——整合の強さ，別のモデルとデータ

**[§5](#5-主結果) の答えは，すべて $\lambda = 0.1$ という一点についてのものである．** 「読み取り精度は上がり，正解率はほとんど落ちない」は，二つとも単一の測定であって，読み取り精度が安く買えたのか，代償がまだ始まっていないだけなのかを区別できない．区別するには，同じ二つの量を複数の強さで測って並べるほかない．

$\lambda \in \lbrace 0.03,\ 0.3,\ 1.0 \rbrace$ を追加する（baseline の $\lambda = 0$ と proposal の $\lambda = 0.1$ は既に測ってあるので走らせ直さない）．乱数種は 42 の1本から始める——曲線の形は1本で見え，区間を締めるのは形が見えてからでよい．読めるのは，読み取り精度が飽和する強さ，正解率が乱数種のばらつきを超えて落ち始める強さ，そして両者の隔たり（**整合は安く買えるのか**——一点では答えようのなかった問い）である．追加の3回は，研究室機で学習した（2026-11-25〜26，計9時間31分）．

**強さの各点では，第16層の末尾の相対感度（→ [§A.4](#a4-利用が伴っていないをどう測ったか三段の測定) 第3段）も測る．** 強さとともに単調に下がれば，[§5.3](#53-読み取りやすさの増加に答えの生成での利用は伴っていない) の低下は整合の強さに応じて起きると書ける．単調でなければ，§5.3 の低下を強さに応じたものとは書かない．乱数種が1つなので区間は作れず，向きと形だけを読む．単調かは，幅 $m = 32$（→ [§8.5](#85-掛ける場所と方向を変えても構造は使われないか) 第1歩）の値が，$\lambda = 0, 0.03, 0.1, 0.3, 1.0$ の順に，どの段でも下がるかで決める．$\lambda = 0$ と $0.1$ の点には，同じ乱数種 42 の baseline と proposal の値を使う．測定は §8.5 第1歩のマップと同じものである．

**結果（2026-11-26）——読み取り精度は強さとともに上がり続け，正解率はほとんど動かない．相対感度は $\lambda > 0$ の4点すべてで $\lambda = 0$ より低いが，単調には下がらない．** どの点も乱数種 42 の1本である．

| $\lambda$ | 読み取り精度 | 正解率 | 相対感度，幅 $m = 8$ | 幅 $m = 32$ | 幅 $m = 128$ |
| --- | --- | --- | --- | --- | --- |
| 0（baseline） | 83.2% | 52.98 | 0.382 | 0.284 | 0.228 |
| 0.03 | 94.9% | 53.32 | 0.281 | 0.229 | 0.194 |
| 0.1（proposal） | 95.6% | 53.37 | 0.292 | 0.240 | 0.204 |
| 0.3 | 97.2% | 52.58 | 0.257 | 0.215 | 0.181 |
| 1.0 | 97.5% | 52.63 | 0.287 | 0.241 | 0.206 |

- **読み取り精度は，$\lambda = 0.03$ で既に 94.9% に達し，その先は $\lambda = 1.0$ の 97.5% まで少しずつ上がる．** $\lambda = 0$（83.2%）からの増分の大半は，最も弱い強さで得られる．
- **正解率の $\lambda = 0$ との差は −0.40〜+0.39pt で，baseline を乱数種だけ変えたときの幅（1.14pt，→ [§5.2](#52-正解率はほとんど動かない)）の内側にある．** $\lambda = 1.0$ までに，正解率が乱数種のばらつきを超えて落ち始める強さは見られない．乱数種が1つなので区間は作れず，「整合は安く買える」と言えるのは，この範囲での，乱数種 42 の1本の観察としてである．
- **相対感度（幅 $m = 32$）は，$\lambda = 0$ の 0.284 から，$\lambda > 0$ の4点では 0.215〜0.241 に下がる．しかし $\lambda = 0.03 \to 0.1$ と $0.3 \to 1.0$ では上がる．** 測る前に決めた規則（強さの順に，隣り合うどの組でも下がること）を満たさないので，[§5.3](#53-読み取りやすさの増加に答えの生成での利用は伴っていない) の低下を強さに応じたものとは書かない．幅 $m = 8, 128$ でも同じ形である．乱数種が1つなので，この上下が乱数種の揺れを超えるかは分からない．

掛ける層についても同じことが言える．ただし**強さと層を同時に振らない**——一つの曲線に二つの説明が混ざる．層のほうを先にした．[§5.3](#53-読み取りやすさの増加に答えの生成での利用は伴っていない) が第16層で「利用が伴わない」と答えたからである——出力に近い層で整合すれば，構造が答えの生成から外れる余地はその分小さい．最初の2点（第8層・第24層，乱数種 42）は測ってあり（→ [§A.5](#a5-整合する層を変えた試走乱数種1つ)），読み取り精度は層を変えても同じ高さに着く．掛けた層の末尾の相対感度は [§8.5](#85-掛ける場所と方向を変えても構造は使われないか) の第1歩で測った——同じ乱数種の baseline に比べて，第24層では下がり，第8層では上がった．残るのは，乱数種を揃えて区間を作ることである．複数の層に同時に掛けることは，学習の側では実装してある（層ごとの損失を平均する）が，分析の側は一つの層に掛けた run しか読まないので，読む側の実装が要る．回していない．

**掛ける層を変えて乱数種5つで学習し直し，加工による表現の動きも測る——§8.5 の第2歩より先に行う（2026-11-27 に決めた）．** 学会で示した結果（[§5](#5-主結果) の三つと，[§A.6](#a6-表現の頑健性画像を加工したときの表現の動き) の比）は，どれも第16層に掛けたものである．層を変えた2本（→ [§A.5](#a5-整合する層を変えた試走乱数種1つ)）は乱数種 42 の1本ずつである．その正解率の，同じ乱数種の baseline との差（+0.68／+0.55pt）は，baseline を乱数種だけ変えたときの幅（1.14pt）の内側にあって向きを決められず，加工による動きは測っていない．掛ける層を変えて，§5 と §A.6 の量の読みが第16層と違えば，学会の結果が及ぶのは第16層に限られる．これを先に確かめる（本人の判断）．

- **学習する．** baseline と，第8層・第16層・第24層に掛けた proposal を，乱数種 42–46 で学習する（20回，1回 約2時間53分で計約58時間）．baseline と第16層の proposal には [§5](#5-主結果) と [§8.1](#81-表現の頑健性の向きを決める乱数種を足す) の run が，第8層・第24層に掛けた乱数種 42 の proposal には §A.5 の run が既にあるが，使わずに学習し直す．並べる値を，一つの版のコードと環境で一度に出すためである（本人の指示，2026-11-25）．
- **測る．** 正解率と読み取り精度と掛けた層の末尾の相対感度は，[§5](#5-主結果) と同じく乱数種 42–44 の3本で，加工による動きの比は [§A.6](#a6-表現の頑健性画像を加工したときの表現の動き) と同じく 42–46 の5本で，同じ乱数種の baseline との差と区間を出す．読み取り精度と加工による動きは，その run が整合を掛けた層で測る．baseline は，読み取り精度と相対感度と加工による動きを，3つの層すべてで測る．加工による動きの測定は，§A.6 と同じく一度の順伝播で複数の層を読むので，baseline は乱数種ごとに1回で3つの層を測る．1回 約32分を20回，計約11時間である．
- **読む．** 第16層の読み——読み取り精度は上がる，正解率はほとんど変わらない，相対感度は下がる，比は小さくなる——が，第8層と第24層でも [§4.3](#43-乱数種3つのまとめ方) の規則で保たれるかを，量ごとに書く．保たれない量があれば，学会の結果はその量について第16層に限られると書く．第16層の差が §5・§A.6 の値から外れるなら，その外れも報告する．
- **ablation は学習しない．** 問うのは，proposal − baseline の読みが掛ける層を変えても保たれるかである．保たれない量が出たら，その層で ablation を学習し，ラベルの意味に帰せるかを確かめる．
- **要る実装．** 層の2点の学習は，乱数種 42 の proposal だけを回す形で実装してある．乱数種と群を広げることと，加工による動きを run ごとにその run が整合を掛けた層で測ること（いまは全 run を同じ層で測る）は，実装が要る．

**モデルとデータセットを増やすのは，このどれよりも高い．** [§7](#7-限界) の「適用範囲は一点である」を外すには，別の規模の VLM と別のデータセットで同じ測定を繰り返すほかない．ただし別のデータセットには，署名を作れることが要る——GQA を選んだのは functional program が付いているからで，注釈の無いデータセットでは署名そのものが定義できない．したがって規模を振るほうが先で，データセットを替えるにはまず署名に代わる形式化が要る．

### 8.5 掛ける場所と方向を変えても，構造は使われないか

**[§5.3](#53-読み取りやすさの増加に答えの生成での利用は伴っていない) は，整合した構造が答えの生成に使われるかに，一次近似の範囲で答えた——答えが整合した位置に頼る度合いは2割前後下がり，ラベルを並べ替えた群では下がらない．** 残るのは，掛ける場所と方向を変えれば構造が使われるかである．一次近似の留保（非線形の経路まで含めても同じことが言えるか）は，[§7](#7-限界) に残す．学会発表（PCSJ/IMPS 2026，2026-11-17）で受けた質問のうち3問は，掛ける場所と強さを問うた——causal attention のもとでの情報の流れ，整合の強さと層，掛ける場所を決める根拠である．強さは [§8.4](#84-及ぶ範囲を広げる整合の強さ別のモデルとデータ) で扱う（質問の記録は [presentations/20261116_PCSJ-IMPS2026_質疑.md](../presentations/20261116_PCSJ-IMPS2026_質疑.md)．文は発表者の聞き取りで，質問者の言葉そのものではない）．

[§3.3](#33-どこに掛けるか射影を挟まない中間層の一点) は，構造が答えの生成に関与しない道を二つ挙げた．一つは位置の道である——後段の16層が使える情報は第16層の出力にある全位置の状態で，整合したのはそのうち末尾の1本だけなので，後段は他の位置から答えを組み立て直せる．もう一つは方向の道である——同じベクトルの中でも，動かしても答えがほとんど変わらない方向に構造が載れば，答えの生成には関与しない．§5.3 では，答えの依存が下がり，第16層で答えを動かす方向の特権も消えた（→ [§A.4](#a4-利用が伴っていないをどう測ったか三段の測定)）．

そこで三つの歩みで進める．第1歩は第2歩で掛ける場所を決め，第2歩は答えの依存の大きい場所に掛け直して位置の道を狭め，第3歩は掛ける方向を限って方向の道を塞ぐ．

**第16層の末尾のベクトルを別の問のものと入れ替える介入は，採らない．** 入れ替えると，署名だけでなく画像と質問文の情報も替わる．署名が違う問と入れ替えたときを処置とし，署名が同じ問と入れ替えたときを対照にしても，質問文の替わり方は揃わない——署名が同じ問どうしは質問文も似ている（質問文の言い回しだけで署名を 69.7% 見分けられる．[§5.1](#51-署名の読み取りやすさは大きく上がる)）．処置と対照の差からは，署名の寄与と質問文の近さの違いを分けられない（本人の指摘，2026-11-19）．

#### 第1歩——答えが依存する層と位置のマップを作る

**[§A.4](#a4-利用が伴っていないをどう測ったか三段の測定) 第3段の相対感度を，第16層の末尾の1点から，全層・全位置へ広げる．** 第 $l$ 層の出力（$l$ 個目の層を出たベクトルの列）の位置 $i$ のベクトルを $h_{p,l,i}$，そこから読み出し $r_p$ へのヤコビ行列を $J_{p,l,i}$ として

$$
e_{p,l,i}(u) = \frac{\lVert J_{p,l,i}^{\top} u \rVert \cdot \lVert h_{p,l,i} \rVert}{\lVert r_p \rVert}
$$

と定める．第16層の末尾では §A.4 の $e_p(u)$ に一致する．方向 $u$ とプロンプトは §A.4 と同じものを使い，§A.4 と同じく方向とプロンプトについて平均した $\bar{e}_{l,i}$ を，縦に層，横に位置を取ったマップの色にする．3群 × 3乱数種で測り，[§4.3](#43-乱数種3つのまとめ方) の規則でまとめる．第32層の出力は読み出しそのものなので，この層の値は定義から末尾で 1，ほかの位置で 0 になる．

**場所の選択と判定は，幅 $m = 32$ で読む．** §A.4 は三つの幅（$m = 8, 32, 128$）で報告するが，場所を一つ選ぶ規則と，表の行を一つ決める判定には，幅が一つ要る．マップを測る前（2026-11-20）に，中央の $m = 32$ に決めた——§A.4 で proposal の低下が最も大きかった幅（8）でも，最も小さかった幅（128）でもない．ほかの二つの幅の値は，並べて報告する．この幅は，第2歩の判定と，[§8.4](#84-及ぶ範囲を広げる整合の強さ別のモデルとデータ) の強さの曲線の読みにも使う．

**横軸の位置は，プロンプトの並びに沿ってそろえる．** プロンプトは，書式の頭の3トークン（`<|im_start|>`・`User`・`:`），画像の67トークン（区切りの3トークンと64個の画像トークン），質問文，書式の後ろの5トークン（`<end_of_utterance>`・改行・`Ass`・`istant`・`:`）の順に並ぶ（SmolVLM-500M-Instruct のプロセッサで組んで確かめた）．最後の `:` が整合した末尾である．問によって長さが変わるのは質問文だけなので，先頭の70位置と質問文は先頭から，最後の5位置は末尾から数え，質問文の各列に入った問の数を添える．質問文を先頭から数えるのは，疑問詞のような頭の語が同じ列にそろい，手順の違いが表れやすいと考えるからである（確かめていない）．右側に詰め物を足して長さを揃えたバッチ（§A.4 の実装はこの形である）の列番号のままでは，質問文の長さに応じて末尾の列が問ごとにずれるので，そのまま平均しない．

**一次の感度は，位置や層のあいだで保存されない．** 各点の値は，その点だけを動かしたときの読み出しの動きで，点ごとに独立に決まり，足して一定になる割合ではない．末尾で下がった分が他の点で上がるとは限らず，全部の点が一斉に下がることもありうる．末尾への依存が下がった分を他の位置が担った可能性はあるが，それを一次の感度の増減で示すことはできない．だから proposal と baseline のマップの差から「依存が他の位置へ移った」かは判定せず，この歩みの役目を掛ける場所の選択に絞る．

**読むのは二つである．**

- **baseline のマップ**——第2歩で掛ける場所を選ぶ元にする（選び方は第2歩）．
- **proposal − baseline のマップの差**——記述として報告する．ablation でも同じ向きに動くなら，ラベルの意味ではなく，同じ位置に対照学習を掛けたこと自体の効果と読む（→ [§4.2](#42-三つの群)）．

### A.1 「読み取りやすさ」の測定と，二つの対照

**プローブ（[§5.1](#51-署名の読み取りやすさは大きく上がる)）．** 長さ1に揃えた表現 $z \in \mathbb{R}^{H}$ に重み行列 $W \in \mathbb{R}^{C \times H}$ を掛け，得られたベクトル $Wz \in \mathbb{R}^{C}$ の第 $c$ 成分を $c$ 番目の署名のスコアとする（ここで $C$ は署名の種類数）．最も高い署名 $\arg\max_{c}(Wz)_c$ がプローブの答えで，当てはめるのは $W$ だけである．評価側でこの答えが正解の署名と一致した問の割合が読み取り精度である．

**プローブが読むのは，整合損失が触るベクトルそのものである**（第16層の，質問を読み終えた位置．1問あたり 960 次元が1本）．同じベクトルだからこそ，読み取り精度の増分を整合の効果として読める．しかもこの位置は画像と質問文だけを読み終えた時点にあり，causal attention のもとで後ろは見られないので（→ [§3.3](#33-どこに掛けるか射影を挟まない中間層の一点)），評価時のバッチが正解を含んでいても，それがこのベクトルへ入ることはありえない．

**当てはめと打ち切り．**

- 当てはめ側と評価側の両方に例が要るので，**まず 10 問以上ある署名に限る**——報告用の 12,578 問・904 署名から，10,990 問・145 種が残る．
- 残った 10,990 問を，**問ごとに確率 1/2 で当てはめ側と評価側に振り分ける**（乱数種は固定）．
- **当てはめ側からさらに2割を取り分け，そこでの読み取り精度が最も高かった時点の写像で評価する**（early stopping）．評価側には一度も触れない．固定のステップ数で全群を打ち切ると，当てはめの速さの違いが，担っている情報の量の違いに見えてしまうので採らない．打ち切りに使う指標は，報告する指標と常に同じにする．
- **床**は，評価側で最も多い署名が占める割合である（当てはめを一切せず，常にその署名と答えても当たる下限）．

**二つの対照．** GQA の質問文は program と同じ質問パターンから自動生成されているので，質問文の言い回し（どの語が現れ，どの2語が隣り合うか）と署名は，作りからして相関している（→ [§3.1](#31-タスク署名解き方を比べられる形にする)）．この交絡を切るために二つ置く．

1. **言い回しプローブ．** 表現の代わりに質問文の言い回しを入力にした，同じ線形分類器．その語が現れるかどうかを語ごとに 0/1 で並べたものを入力にする——回数ではなく有無で，語の順序は残らない．語順をすべて捨ててしまわないよう，隣り合う2語の組を同じ形に並べたものも作り，両方を測って高いほうを報告する．列に並べる語（組）は頻度上位 8,000 までに限る——本節の分割では単語 2,386 種が全て収まり，上限が効くのは語と2語の組を合わせた形（13,808 種．うち2語の組が 11,422 種）だけである．これは「質問文の語だけで当たる水準」であって，質問文から原理的に取れる情報の上限ではない——語の順序も文の構造もほとんど使っていないので，質問文をもっと丁寧に読めばこれより上がありうる．群間の差を測る対照ではなく，得られた値が質問文を読むだけで説明できてしまわないかを見る基準である．
2. **書き出しを分離した分割．** 質問文の先頭4語が同じ質問は，当てはめ側と評価側に分かれないよう，まとめて一方へ寄せる．評価側では質問の書き出しが必ず未見になるので，書き出しと署名の対応を覚えるだけでは当たらない（ただし5語目以降の語まで未見になるわけではない）．寄せた結果，1種が片側だけに落ちて採点できなくなるので，この分割で残るのは 10,978 問・144 種である．

**ablation の 81.0% の読み方．** 類似度が 0.99 を超えても署名の情報は消えない——全ベクトルが細い円錐に収まっても，平均方向に直交する小さな成分が署名によって系統的に変わっていれば，分類器の重みの大きさに制限は無いので線形写像はそれを取り出せる．したがって ablation の 81.0% は「壊し損ねた残り」ではなく，言語モデル損失 $\mathcal{L}_{\mathrm{LM}}$ だけで保たれる水準である．

**質問の形式を除いても残るか（補足）．** 本文はこの検査に依らない．語数や答えの型といった質問の形式（Sahoo らの言う task format）は解き方とは別のもので，Sahoo らは，3つの推論ベンチマークを 100% で分離していたプローブが，出典・選択肢数・応答長で説明できる分を差し引いた途端，でたらめに答えたのと変わらない水準まで落ちる例を示した．本研究では出典と選択肢数は定義上存在しない（全問が単一コーパスの同一生成過程から来ており，多肢選択ではない）ので，残るのは長さである．問ごとに質問文の語数／答えの文字数／答えが yes/no かどうか（そうなら 1，違えば 0）の3つを数え，平均 0・標準偏差 1 に揃えて切片と並べた行列を $F$，長さ1に揃えた表現を並べた行列を $Z$ とする．表現の各次元をこの3つから ridge 回帰（最小二乗に，係数が大きくなりすぎないための罰則を足したもの．罰則の強さは $\alpha = 1$ で，切片には掛けない）で予測し，予測できた分を差し引く：

$$
Z \longmapsto Z - F(F^{\top}F + \alpha D)^{-1} F^{\top} Z,
\qquad
D = \mathrm{diag}(1, 1, 1, 0)
$$

これを**残差化**と呼び，残った分の上で同じプローブを当て直す．差し引いた後に長さは揃え直さない——揃え直せば，長さを大きく失った行も，ほとんど失わなかった行も，同じ長さに見えてしまう．署名ラベルは回帰に入らないので，当てはめ側と評価側の両方の行で回帰しても正解は漏れない．残差化は，署名が形式と正当に共有している分も一緒に落とすので，残差化後の値は，形式を除いてなお残る量の下限である．結果は次のとおりである．この3つだけを入力にしたプローブは 35.3%（書き出しを分離した分割では 34.3%）で，床に近い．残差化した表現の上での読み取り精度は baseline 82.9%・proposal 95.6% で，整合の効果は 13.02pt から 12.67pt へ 0.35pt 動くにとどまる（書き出しを分離した分割では 14.46pt → 14.61pt）．Sahoo らの設定では形式を除いた途端に読み取り精度がでたらめの水準まで落ちたが，本研究の proposal は除いても 0.33pt しか落ちない（ablation の落ち幅だけは 1.26pt とやや大きく，一方向に集まった表現に残る署名の情報は，proposal の表現のそれより形式に寄っている）．

### A.2 演算子の組成も，読み取れるようになる

[§5.1](#51-署名の読み取りやすさは大きく上がる) には反論が立つ——**整合損失は署名どうしの見分けやすさを上げ，プローブは署名どうしの見分けやすさを測るので，学習が自分の教えたことを読み返しているだけではないか．** これに答えるために，損失が一度も教えていない構造で測る．整合損失が与えているのは「署名が同じか違うか」だけであり，署名がどの演算子から組み立てられているかも，二つの署名が演算子を共有することも，一切教えていない．

- **ラベルを「使われている演算子の集合」に取り替える**——報告用データに現れる 118 種の演算子のうち，延べ 50 回以上現れる 46 種について，含むか含まないかを並べた 0/1 ベクトルにする．
- **分割を署名単位で切る**——904 署名のうち 449 種をプローブの当てはめ側，残る 455 種（4,874 問）を評価側に置く．評価側の署名は当てはめ側に一度も現れない（個々の演算子は当てはめ側にもある）．ただし目標は演算子の有無であって順序ではなく，46 種に入らない稀な演算子も落とすので，評価側の 455 種のうち 220 種（2,686 問，55.1%）は当てはめ側のどれかの署名と同じ目標ベクトルを持つ（`select > verify rel` と `select > filter depth > verify rel` のように）．目標ベクトルまで未見なのは評価側の 44.9% の問であり，下の率は評価側の全問について測っている．「未見」はいずれもプローブにとってであって，モデルにとってではない．

報告は AUC と完全一致率の2つである．**AUC** は，ある演算子を含む問と含まない問を1組ずつ取ったとき，含む側により高いスコアが付く割合である（でたらめなら 0.5．評価側に正例と負例の両方がある 42 種について平均する）．**完全一致率**は，46 個の予測がすべて正解と一致した問の割合である．当てはめと打ち切りは [§A.1](#a1-読み取りやすさの測定と二つの対照) と同じ手順で，取り分けた2割で見るのはここでは AUC である（打ち切りに使う指標は，報告する指標と常に同じにする）．

| 署名で分けた評価側（4,874 問）について | 演算子ごとの AUC | 組み合わせの完全一致率 |
| --- | --- | --- |
| baseline（整合前） | 0.896 | 36.3% |
| **proposal（整合後）** | **0.952** | **44.5%** |
| ablation | 0.918 | 32.7% |
| （参照）言い回しプローブ（質問文だけを入力） | 0.936 | 29.2% |

- **整合は，評価側の完全一致率を 36.3% から 44.5% へ上げた（+8.2pt）．** 「署名が同じか違うか」しか教えられていないモデルが，損失が小さくしようとしていない量を言い当てている——[§5.1](#51-署名の読み取りやすさは大きく上がる) の増分は，学習が自分の教えたことを読み返した結果ではない．
- **ablation では上がらない（32.7%，整合前より −3.5pt）．** 対照学習という形式そのものではなく，ラベルの意味がこの増分を生んでいる．
- **ただし増分は [§5.1](#51-署名の読み取りやすさは大きく上がる) より小さい．** 完全一致率では +8.2pt だが AUC では +0.057 にとどまる．損失が直接作っている構造から離れるほど，増分は小さくなる．
- **演算子を1つずつ判別する能力では，整合前の表現は言い回しプローブに劣る**（AUC 0.896 対 0.936）．整合後にようやく +0.016 上回るが，言い回しプローブは質問文から取れる情報の上限ではないので，これを「表現は質問文より多くの情報を持つ」と読んではいけない．差が大きく開くのは組み合わせ全体を当てる課題（完全一致率）でのみである（整合前でも +7.1pt，整合後は +15.3pt）．
- **この所見は [§5.3](#53-読み取りやすさの増加に答えの生成での利用は伴っていない) の範囲限定を受ける．** 組成も表現の形式の話であって，答えの生成での利用を示すものではない．

### A.3 正解率が上がらない理由——頻度層別と，正誤で分けたプローブ

**全体の正解率は，頻出する署名に支配される．** 整合による利得が現れうるとすれば，モデルの学習データに一度も現れない署名と，ほとんど現れない署名という，どちらも稀な側である——全体の平均を見ているかぎり，そこに効果があってもなくても数値は動かない．「効果が無かった」と「効果が現れうる場所で測っていなかった」を分けるために，報告用の 12,578 問を，その質問の署名がモデルの学習データに何回現れたかで五つの層に分ける．群間の比較は各層の中で同じ質問集合の上で行う（[§4.3](#43-乱数種3つのまとめ方) と同じ，乱数種ごとに対にした差）．層別には問ごとの正誤が要るので，こちらで採点し直し，その全体値が公式の値と一致することを確かめたうえで使う．

| 署名が学習に現れた回数 | 質問数 | yes/no の割合 | baseline | proposal | proposal−baseline |
| --- | --- | --- | --- | --- | --- |
| 0（未見） | 162 | 91.4% | 67.70 | 68.11 | +0.41 |
| 1–10 | 320 | 78.1% | 71.77 | 69.27 | −2.50 |
| 11–100 | 778 | 69.4% | 62.17 | 61.70 | −0.47 |
| 101–1,000 | 1,567 | 57.2% | 64.52 | 64.39 | −0.13 |
| 1,001+ | 9,751 | 27.6% | 50.26 | 50.32 | +0.06 |

**利得の現れる層は無い．** 信頼区間が 0 を離れる層は一つも無く，5つの層のうち3つで proposal が下回る．低下が最も大きいのは 1–10 の層で，3つの乱数種すべてで下回り（乱数種ごとに $-0.62 / -3.75 / -3.12$），差は −2.50（区間 $[-6.61, +1.61]$）——学習にほとんど現れなかった署名で正解率が下がる傾向はあるが，区間が 0 を跨ぐので，向きは未確定である．未見（0回）の層は 162 問しかなく，乱数種ごとの差は $+6.17 / -3.70 / -1.23$ と符号が割れ，区間は $[-12.36, +13.18]$ に広がる——平均が +0.41 であることを，利得の証拠として読んではいけない．なお，行ごとに正解率の水準が違うのは署名の出現回数ではなく質問の型を映しているが，群間の比較は各行で同じ質問集合の上で行うので，この交絡を受けない．

**誤答した質問でも，署名は第16層から読み取れる．** プローブを正誤で分けて当てると，どの群でも誤答した質問のほうが読み取り精度がわずかに高い（baseline 81.0% 対 84.9%，proposal 95.4% 対 96.4%）．つまりモデルが答えを外した質問でも，その第16層の表現からは正しい署名が 96.4% の精度で読み取れる——署名の情報が表現に在ってなお，答えは誤っている．そこから立つ説明の候補は，誤答が署名より後の段階で起きていることである．（ただし，誤答側のほうが高いことを「誤答した問のほうが署名を読み取りやすい」と読んではいけない——誤答は最も多い署名 `select > relate > query` に偏っており，正解側と誤答側とでは入っている質問の中身が違う．結論が要求するのは誤答側の水準が高いことだけである．）

**この「後の段階」がどこかは測っていない**——視覚的な対象の特定か，演算子列の実行か，その双方かは分けていない．また [§5.3](#53-読み取りやすさの増加に答えの生成での利用は伴っていない) のとおり proposal では署名が読めても答えがそれを以前ほど読んでいないので，proposal について「誤りは署名より後の段階で起きている」と断定はできない（baseline にはこの追加の留保は掛からないが，説明の候補であることは変わらない）．

### A.4 「利用が伴っていない」を，どう測ったか——三段の測定

**判定するのは次の二択である．**

- **中立**——整合した構造は答えの生成に関与しているが，正解率を上げも下げもしない．
- **不一致**——整合した構造は第16層で答えを動かす方向には集中しておらず，読み取りやすさの増加に，答えの生成での利用が伴っていない．

[§5.2](#52-正解率はほとんど動かない) の「正解率が変わらない」は，二つのどちらとも矛盾しない．

**素朴な方法——整合を掛けた表現を壊して出力の変化を見る——は採らない．** 言語モデルには，ある注意層を除くと別の層がそれを補う自己修復が知られており（McGrath ら），「壊しても出力が変わらない」は「その層が答えの生成に寄与していない」ことを意味しない．代わりに問うのは，署名が表現のどこに載っているかである．表現から情報を除いて振る舞いの変化を見るやり方は Elazar らの **amnesic probing** として確立しており，同じ本数のランダムな方向を除いて比べる **Rand 対照**も彼らが既に使っている．本研究は情報を除く介入はせず，そこから借りるのは，同じ本数のランダムな方向と比べるという対照の考え方である（第1段・第2段の $R_m$）．新しいのは測り方ではなく，測る対象である：既にある性質ではなく，損失で作り込んだ構造が使われているかを問う．

三つの段を踏む．第1段と第2段は，構造がどこに載っているかを問う——第1段は出力層が読む方向をそのまま第16層に当て，第2段はそれを第16層へ引き戻したもの（第16層で答えを動かす方向）を当てる．第3段は，答えがその位置にどれだけ頼っているかを問う——載っている場所が分かっても，そこが読まれる度合いは分からないからである．

#### 第1段——出力層が読む方向を，そのまま当てる

**モデルを走らせずに済み，保存済みの表現と出力層の重みだけで完結する．**

1. **出力層が読む方向を集めて，部分空間 $U_m$ を作る．** 出力層は最終層の表現に重み行列を掛けて語ごとのスコアを出す．その1行が1語に対応し，どの語が選ばれるかを決めているのはこれらの行が指す方向である．GQA の答えは閉じた語彙なので（報告用データで 722 種），答えの先頭トークンに対応する行だけを抜き（先頭に空白が付く符号化と付かない符号化の両方を取り，重複を除いて 1,085 行），列ごとの平均を引いて，上位 $m$ 個の主成分を正規直交な列として並べたものが $U_m \in \mathbb{R}^{H \times m}$ である．この $U_m$ は群ごとに，その群自身の出力層から作る（整合は出力層の重みも動かすので，群をまたいで一つの $U_m$ を使えば，出力層どうしの違いが読み取り精度の差として現れてしまう）．幅 $m$ は 8／32／128 の3通りを試す．
2. **$U_m$ の中と外で読み取り精度を比べる．** 長さ1に揃えた第16層の表現 $z$ を，中の成分 $U_m^{\top} z$ と外の成分 $z - U_m U_m^{\top} z$ とに分け，[§5.1](#51-署名の読み取りやすさは大きく上がる) と同じプローブをそれぞれに掛ける．対照として，出力層と何の関係もない $m$ 次元のランダムな正規直交基底 $R_m$ を置き，中と外の両方をこれと突き合わせる（次元が広ければどんな部分空間でもある程度当たるので $U_m$ の中で当たること自体は証拠にならない．また $H$ 次元から $m$ 方向を抜いただけの表現もほとんど落ちないので，外でなお読み取れること自体も証拠にならない）．$R_m$ は5本引いて平均する——同じ幅でも引き方を変えれば別の部分空間になり，そこで測った増分も変わるので，各本の値も残して判定量をその散らばりと突き合わせられるようにする．

**$U_m$ は最終層の空間で定義した部分空間であり，それを第16層のベクトルに当てている．** 両者は同じ $H$ 次元だが，同じ空間ではない——この近似が成り立つかどうかを，第2段が測る．

#### 第2段——同じ方向を，第16層へ引き戻してから当てる

第16層と出力層のあいだには16層が挟まっている．**その16層を線形化すれば，出力層が読む各方向は第16層にも像を持ち，それが第16層で答えを動かす方向である．** これが J-lens の考え方である（Gurnee ら）．ここでは $U_m$ の $m$ 本をこの向きに引き戻し，直交化したものを $J(U_m) \in \mathbb{R}^{H \times m}$ と書いて $U_m$ の代わりに使う．要るのは与えられた方向に対するベクトル–ヤコビ積だけなので $m$ 本それぞれについて逆伝播を1回流せば足りる．平均を取るのはプロンプトについてであって，位置についてではない——本研究が問うているのは一つの位置にあるベクトルだからである．報告用データから引いた 64 問で平均する．引き戻す前後の向きの隔たりも測る（各方向とその像のコサインの絶対値の平均．第1段はこれが 1 であると置いていた）．

#### 第3段——答えが，その位置にどれだけ頼っているか

第2段は引き戻した方向を正規直交化して向きだけを使い，長さを捨てている．捨てた長さがここで要る量である——第16層を動かしたとき答えがどれだけ動くかは，方向の重なりではなく，その大きさが決める．生の長さは群間で比べられない（整合は第16層の表現の大きさも読み出しの大きさも動かしうる）ので，両端の大きさで割り，相対感度（relative sensitivity）として報告する．プロンプト $p$ と方向 $u$ について，第16層のベクトルを $h_p$，**読み出し**（最終層の同じ位置のベクトル．出力層はこれに重み行列を掛ける）を $r_p$，前者から後者へのヤコビ行列を $J_p$ として

$$
e_p(u) = \frac{\lVert J_p^{\top} u \rVert \cdot \lVert h_p \rVert}{\lVert r_p \rVert}
$$

と定める．**第16層を，読み出しを $u$ 方向へ最も動かす向き（$J_p^{\top} u$ の向き）に相対的に1%動かしたとき，読み出しが $u$ 方向に，自身の大きさの何%動くか**という無次元の量である．これを $m$ 本の方向とプロンプトについて平均したものを $\bar{e}$ と書く（先にノルムを取ってから平均する——向きの揃わないベクトルの平均は短くなり，大きさではなく一致度の話になってしまう）．プロンプトの本数は仮定せず，相対感度の累積平均と第2段の方向が先頭から何問で落ち着くかを，同じ逆伝播から出す．

**ablation が要る理由は [§4.2](#42-三つの群) と同じである**——相対感度が下がったとして，それがラベルの意味によるのか，同じ位置に対照学習を掛けたこと自体によるのかは，ラベルを並べ替えた群と比べなければ分かれない．

| 結果 | 意味 |
| --- | --- |
| proposal の相対感度が baseline より小さい | **不一致**——答えは，整合が触った位置に以前より頼らない |
| 3群で変わらない | **中立**——構造は広がったが，位置への依存は落ちていない |
| proposal のほうが大きい | 整合は依存をむしろ強めた．[§5.2](#52-正解率はほとんど動かない) の正解率が動かないことと突き合わせる必要がある |

#### 判定量

**判定は，読み取り精度の水準ではなく，[§5.1](#51-署名の読み取りやすさは大きく上がる) の増分がどこで生き残るかで行う．** 水準は部分空間の幅だけで決まり，増分は $U_m$ でもランダムな部分空間でも同じように現れる——残るのは両者の差である．そこで $g(V)$ を，部分空間 $V$ の中の座標だけで測ったときの整合の効果（proposal の読み取り精度 − baseline のそれ）とし，同じく $g'(V)$ を，その $V$ に載る分を抜いた残りで測った同じ効果とする．判定量は，各幅 $m$ について

$$
\Delta_m = g(U_m) - g(R_m),
\qquad
\Delta'_m = g'(U_m) - g'(R_m)
$$

の2つである（中が $\Delta_m$，外が $\Delta'_m$．第2段では $U_m$ を $J(U_m)$ に置き換える）．中の $\Delta_m$ が正に立てば構造はその部分空間（第1段なら出力層が読む方向，第2段なら第16層で答えを動かす方向）に載っており，利用が伴っていないという読みは否定される．外の $\Delta'_m$ が正に立てば構造は出力が読まない側に載っている．どちらも立たなければその段では決着していない．3つの乱数種の符号が揃わない $\Delta$ は学習の揺れの中に，対照5本の標準誤差の2倍を超えない $\Delta$ は引き方の揺れの中にある．

#### 結果

**第1段が置いた近似は，成り立っていなかった．** 出力層が読む方向とその第16層での像とのコサインは，絶対値の平均で baseline 0.229・proposal 0.244・ablation 0.212 である．1 に近ければ第1段の部分空間がそのまま使えたことになるが，そうではない．そのことは部分空間そのものの性質にも出ている．部分空間 $U_m$ か $J(U_m)$ の中で署名が，同じ幅の $R_m$ の中でより高く読めることを，**特権**と呼ぶ．出力層から直に取った $U_m$ に，整合前の群はこの特権を持たない（baseline は $U_m$ の中を $R_m$ の中より +0.10／−1.43／−1.17pt しか違えずに読む）．引き戻した $J(U_m)$ では $m = 8, 32$ で +2.82／+1.69pt になり（幅 $m = 128$ では −0.17pt と差が無い）．引き戻して初めて，署名を担う方向が捉えられている．

**ablation の第1段・第2段の値は，どこでも読まない．** 判定量はもともと proposal と baseline の差で，ablation は入らない．そのうえ狭い部分空間では，ablation のプローブの当てはめが最頻クラスの率（0.288）から離れない——幅 $m = 8$ では，第1段の中の3本と $R_m$ の15本のすべて，第2段の $R_m$ の15本（両段で同じ引き）がそうで，幅 $m = 32$ では両段とも $R_m$ の3本である．同じ ablation の $J(U_8)$ の中は 0.39〜0.42 まで上がるので，この値は表現の中身ではなく当てはめの失敗を映す．$J(U_m)$ と $R_m$ の差を取ると，失敗がそのまま大きな見かけの差になる（幅 $m = 8$ で +11.92pt）．baseline と proposal では，止まった当てはめは0本である．

- **第1段は決着に使わない．** 中の $\Delta_m$ で3つの乱数種の符号が揃うのは $m = 32$ だけで，その +1.23pt は引き方の標準誤差の2倍を超えて立つ．しかし $U_m$ は整合前から特権的でなく，引き戻しで各方向は $|\cos| = 0.23$ まで回り，同じ幅の第2段では符号が反転して立つ（−1.37pt）——この $U_m$（出力層が読む方向）の中で測った差は，第16層で答えを動かす方向についての差ではない．
- **第2段では，中の $\Delta_m$ は一度も正に立たない．** 立つのは $m = 32$ の −1.37pt（負）だけで，幅 $m = 8$ の −3.08pt は乱数種の符号が割れ，幅 $m = 128$ の +0.21pt は引き方の標準誤差の2倍を下回る．中立を示す証拠——第16層で答えを動かす方向で増分が保たれること——は，どの幅でも得られない．
- **外の $\Delta'_m$ は，第2段では $m = 128$ の +0.21pt が一つだけ正に立つ．** 定義どおりに読めば構造の一部は出力が読まない側に載っているが，外の側はもともと差が出にくいうえ（960 次元から 128 方向を抜いても読み取り精度はどの群でも 0.5pt 以内でしか動かない），立った値も 0.21pt と小さい——外の値は，どちらの向きにも単独では証拠として重ねない．
- **整合前にあった特権は，整合後に消える．** baseline は $J(U_m)$ の中を，幅 $m = 8, 32$ では $R_m$ より高く読み（+2.82／+1.69pt，3つの乱数種すべてで正），幅 $m = 128$ では差が無い（−0.17pt）．proposal は幅 $m = 8, 32, 128$ で −0.26／+0.32／+0.05pt と，どの幅でも乱数種の符号が割れ，差が無い．ただし $\Delta_m$ の負を「整合が第16層で答えを動かす方向を避けた」と読んではいけない——幅 $m = 8$ の到達点は proposal でほとんど同じ（71.34% と 71.60%）で，差が付いているのは出発点のほう（baseline 47.39% 対 44.57%）である．この観測が確定させるのは，整合後に特権が無いことであって，整合が特権を避けたことではない．

- **proposal は，第16層に頼らなくなっている．** 相対感度は3幅とも下がり，乱数種ごとの変化も −23.6／−24.8／−35.6%（幅 $m = 8$）と3つの乱数種すべてで同じ向きである．表の変化率はこの3つの平均である——[§4.3](#43-乱数種3つのまとめ方) と同じく乱数種ごとに比を取ってから平均するので，表の相対感度の平均どうしから作る比とは僅かに異なる．
- **ablation では下がらない．** −4.3／−0.5／+0.4% にとどまり，3幅とも乱数種の符号が割れる．proposal との落ち幅の差は −23.7／−21.1／−18.5pt で，こちらは3幅・3乱数種のすべてで符号が揃う．依存の低下は，同じ位置に対照学習を掛けただけでは起きず，意味のあるラベルを要する．
- **区間で見ると，128 本の proposal − baseline だけ向きを決められない．** 乱数種を対にした変化率の 95% 区間は −28.0 [−44.4, −11.5]／−21.6 [−38.1, −5.2]／−18.0 [−36.4, +0.3] で，128 本は 0 を含む．proposal と ablation の落ち幅の差の区間は −23.7 [−31.1, −16.3]／−21.1 [−23.9, −18.3]／−18.5 [−20.0, −16.9] で，3幅とも 0 を含まない（保存した乱数種ごとの相対感度から，[§4.3](#43-乱数種3つのまとめ方) の係数 4.303 で計算した）．
- **64 問で足りているかも，同じ逆伝播から確かめた．** 先頭 8／16／32／48／64 問での相対感度の累積平均は，幅 $m = 8$ で baseline 0.3691 → 0.4023，proposal 0.2721 → 0.2883 と，64 問でもなお僅かに動いている．ただし表と同じく乱数種ごとに取った変化率は，幅 $m = 8$ ではどの本数でも −24% から −30% の間にあり（幅 $m = 32$ では −18% から −23%，幅 $m = 128$ では −14% から −20%），低下の向きと大きさは本数に依らない．第2段の方向は 48 問で最終値と $|\cos| = 0.98$（proposal は 0.96）まで近づく．ただしこの指標は 64 問の平均を基準に取るので，64 で 1.000 になるのは定義による．

**二つの測定は，同じ向きを指している．** 構造は第16層で答えを動かす方向に集中して載っておらず，答えはその位置に以前より頼らない——これが [§5.3](#53-読み取りやすさの増加に答えの生成での利用は伴っていない) の結論の根拠である．ただし，これは一次近似の測定である．相対感度は第16層のまわりで線形化した一次の量であり，非線形の経路まで否定しない．しかも下がったのは2割前後であって，答えが第16層をまったく読まなくなったのではない．「使っていない」ではなく「頼る度合いが下がった」が，測定の言える範囲である．

### A.6 表現の頑健性——画像を加工したときの表現の動き

**[§1.1](#11-出力が同じでも内部表現が同じとは限らない) で挙げた出発点の問題に，本研究が応えたかどうかを確かめる測定である．** Wani らが示したのは，出力が同じでも内部表現は変化することだった．署名で整合した群（proposal）でその変化量が小さくなるかを，ここで測る．[§5](#5-主結果) の主結果はこの測定に依らない．

#### 設計

**この見出しの下の設計と判定の表は，走らせる前（2026-10-23）に決めたものである．** 判定の表の行の呼び名だけは，後で「整合した群」から「proposal」に書き直した（ablation も整合損失を掛けた群なので）．中身は変えていない．

**加工は，Wani らが付録で定めた族（加工の種類）と値をそのまま使う．** 画像だけに施し，質問文は触らない．水平方向の巡回シフト（±4・±8・±12・±16 画素），対称な余白付加と切り出し（同じ8通り），0.9 倍に縮小して元の解像度へ戻すもの，0.9 倍に縮小して一様な背景で元の寸法に戻すもの，面内の ±30° 回転，そして幾何が同じで中身だけ違う三つの文字の重ね書き（指示文，同じ長さの無作為な文字列，何も書かない白い箱．三つとも左上の同じ白い箱で，中身だけが違う）——全部で 23 通りを，報告用データの全 12,578 問それぞれに施す．原典 §3.2 は文字の重ね書きを一つに数えて六つの族とし，表1はそれを中身ごとの3行に開いた8行で示す．本研究も表1に倣い，8族として集計する．Wani らが書いていないこと（背景の色，補間，箱の位置と大きさと色，縮小と余白の縮小率と寸法——縮小と同じ 0.9 倍とし，元の寸法に戻した）はこちらで決めた．原典の Table 2 は縮小と余白を1枚あたり2件（3,493 枚に 6,986 件）数えるが，本研究は1通りである．背景は処理系自身が余白に使う中間の灰色，補間は双三次，箱は画像の左上に幅の 55%・高さの 11% である．

**指示文の選び方だけは，原典から逸脱する．** 原典は，モデル自身の加工前の予測以外の選択肢を名指しする「Answer is L」を，1枚に最大3つ作る（v2 の付録 A.6．設計を決めた時点で読んだ v1 にはこの定めが無かった）．本研究は「Answer is yes」か「Answer is no」の一方を問ごとに決める．予測に応じて文を変えると，同じ問が群ごとに違う加工を受け，乱数種と群を対にした比較が加工の違いまで拾ってしまうからである．GQA には選択肢が無いので，名指しする選択肢もそもそも定まらない．

加工は，処理系が縦横を 512×512 に引き伸ばす前の元画像に施す．GQA の画像は長辺が 500 か 640 画素のものが多いので，元画像の1画素はモデル入力の1画素の桁にあたる（512 をその辺の画素数で割った値で，640 画素の辺で 0.8，333 画素の辺で 1.5）．原典は v2 で，空間関係を問う質問では回転や平行移動が正解を変えうると断っている（付録 A.4）．GQA には空間関係を問う質問が多いので，加工が正解を保つという前提はその分だけ弱い．無作為に決まるもの（文字列，指示文の選択，対照で入れ替える画像）は質問 ID から決めるので，どの実行でも同じ問が同じ加工を受ける．

**測る量は，加工前後の表現のコサイン距離（1 − コサイン類似度）である．** 位置は質問を読み終えた位置で，第16層（整合を掛けた位置）と第32層（最終層．Wani らが測った層にあたる）の両方を一度の順伝播から取る．距離そのものは群間で比べない——proposal は異署名の類似度を 0.92 から 0.22 まで下げており，表現の広がり方が群ごとに違う（→ [§4.4](#44-操作の確認整合は表現をどう変えたか)）．Wani らと同じく，無関係な入力どうしの距離の分布（以下**対照**）の平均に対する比（%）と，二つの分布の Cohen's d で報告する．Wani らは，d の分母の標準偏差をどう合わせるかを書いていない（表4・表7の値は，標本数で重みを付けずに等しく合わせた式と合う．これは逆算による推定である）．こちらは，二つの分布の不偏分散を，それぞれの標本数から1を引いた数で重み付けて合わせる（[§4.4](#44-操作の確認整合は表現をどう変えたか) の分離度と同じ作り方）．対照は，同じ質問に報告用データの別の画像を付けたときの距離とする．Wani らの対照は無関係な画像の対で，各画像はそれぞれの問を伴うので，問も変わると読める（原典は明記していない）．本研究の位置は質問の末尾にあり，整合損失は質問どうしの配置を作り変えているので，問まで入れ替えた対照は画像の寄与ではなくその作り変えを測ってしまう．画像だけを入れ替える対照は，この位置の表現を画像がどこまで動かしうるかを測り，加工による移動をその尺度で読む．Wani らの形の対照（別の問と別の画像）も，加工前の表現だけから同時に出す．

**出力の側も同じ測定から出す．** Wani らは，並べた選択肢のうち対数尤度が最も高いものを答えとする（原典 §3.1）．GQA には選択肢が無いので，本研究は貪欲デコードで生成した答えを使う．加工の前後で生成した答えが変わった対の割合（Wani らの instance flip rate）と，一つ以上の加工で答えが変わった問の割合（image vulnerability）を族ごとに出し，答えが変わらなかった対だけで距離を集計した値も添える．「答えが同じでも表現は動く」が本研究のモデルでも起きているかは，この集計が答える．

**まとめ方は [§4.3](#43-乱数種3つのまとめ方) のとおりである．** 群ごとに乱数種の平均と標準偏差，群間は乱数種を対にした差の 95% 信頼区間．判定に使う量は，第16層における，画像だけを入れ替えた対照に対する比である．

| 結果 | 意味 |
| --- | --- |
| proposal の比が baseline より小さい（ablation では小さくならない） | **整合は表現の安定性を高める．** [§1.1](#11-出力が同じでも内部表現が同じとは限らない) の問題に直接応えたことになる |
| 差が無い | 整合が変えるのは**表現の形式だけ**であり，安定性には及ばない——射程を限定した主張になる |
| proposal の比が baseline より大きい | 分離を強めた副作用として脆くなっている．**代償が正解率の上限だけでは済まなくなる**ので，必ず確かめる |

Wani らの表4（ans_mcq_free の埋め込み）では幾何的な加工の変化量は対照の 10% 未満で，対照に迫るのは文字の重ね書きだけである．ただし本研究のモデルは彼らの評価に含まれていないので，どの族で群間の差が出るかは測るまで分からない．**この測定で読めるのは3群のあいだの差である．** 借りるのは指標の形であって，Wani らの数値との比較ではない（彼らは言語側の最終層，Qwen3-VL・LLaVA-OneVision・Gemma-3，SEEDBench・MMMU・POPE で測っている）．

#### 結果

15回の学習（3群 × 乱数種5つ）それぞれの重みで，報告用データの全 12,578 問に 25 回の順伝播（加工前1回，加工 23 通り，対照1回）を通した．乱数種 42–44 の9回を先に測り，[§8.1](#81-表現の頑健性の向きを決める乱数種を足す) のとおり 45・46 の6回を足して，5本で読む．表の族の名は，設計の段落の順に，平行移動（巡回シフト），余白付加と切り出し，縮小（元の解像度へ戻すもの），縮小と余白（一様な背景で元の寸法に戻すもの），回転，指示文の重ね書き，無作為な文字列の重ね書き，文字なしの重ね書きである．以下，太字は区間が 0 を含まない差である．

**判定に使う比は，baseline より小さく，ablation より小さい．** proposal − baseline は乱数種ごとに −4.30／−9.06／−3.62／−2.74／−4.39pt と5本すべてで負で，区間も 0 を含まない．ablation は baseline より大きく（+6.21pt），proposal は ablation より小さい（−11.03pt）．この二つも区間が 0 を含まない．

- **[§8.1](#81-表現の頑健性の向きを決める乱数種を足す) の表では1行目に当たり，距離は逆を向く．** 比の区間は 0 を含まず負で，ablation の比は baseline より大きい．距離そのものは大きくなる向きなので（→ 距離そのものの段落），「整合は表現の安定性を高める」とは書かず，安定性は，比で見るか距離で見るかに依ると書く．設計の段落の判定の表は，比だけで読めば1行目に当たる．この表は比の分母が群ごとに違うと分かる前に作ったものなので，読みは5本の結果を見る前に [§8.1](#81-表現の頑健性の向きを決める乱数種を足す) の表で改めた．
- **族ごとの差は，探索的に読む．** proposal − baseline の区間が 0 を外れるのは，平行移動・余白付加と切り出し・縮小と余白・回転・指示文の重ね書きの5族である．ただし8族を乱数種5つで比べているので，族ごとの結果は確定として扱わない．
- **答えが変わった対が比を動かしているのではない．** 答えが変わらなかった対だけで集計しても，比はほとんど変わらない（23 通りすべてで 14.31／9.62／20.60%，proposal − baseline は **−4.69**pt [−7.80, −1.58]）．

**比の分母は，群ごとに大きく違う．** 第16層の加工による距離の平均（23 通りすべて）は，baseline の $0.89 \times 10^{-3}$ に対して proposal が $2.86 \times 10^{-3}$，ablation が $0.33 \times 10^{-3}$ である．対照の平均は $5.99 / 28.83 / 1.55 \times 10^{-3}$ である．proposal では加工による距離が約3倍に，対照が約5倍になったので，比が下がった．ablation では両方が縮み，対照のほうが大きく縮んだので，比が上がった．比は，群ごとに違うこの尺度で加工による移動を読む量である．Wani らの比（表4）は一つのモデルの中で加工の種類どうしを比べるもので，分母は共通である．本研究は別々に学習した群を比べるので，分母が群ごとに違う．

**距離そのものでは，第16層で向きが逆になる．** 加工による距離の平均の proposal − baseline は +1.97（区間 [+1.58, +2.37]，5つの乱数種すべてで正）で，対照の距離も +22.8（[+20.6, +25.1]）と大きい（単位はどちらも $10^{-3}$）．比で見れば proposal のほうが動かず，距離そのもので見れば proposal のほうがよく動く．距離そのものは表現の広がり方が違う群のあいだでは比べられない（→ 測る量の段落）ので，これを脆くなった証拠とは読まない．同じ理由で，判定に使う比が小さいことも，加工で動きにくくなったことを意味しない．意味するのは，画像を差し替えたときの動きに比べて，加工による動きが小さいことまでである．第32層では，加工による距離（−2.63 [−3.84, −1.41]）も対照（−17.5 [−23.4, −11.6]）も proposal のほうが小さいが，比の差は区間が 0 を含む（−0.12pt [−0.51, +0.27]）．proposal − ablation は，加工による距離で第16層 +2.53 [+2.23, +2.84]・第32層 −3.01 [−3.91, −2.11] で，どちらも区間が 0 を含まない．第16層の ablation − baseline は，距離で −0.56 [−0.81, −0.31] と小さくなり，比とは向きが逆である．

そこで，比の尺度を変えても向きが残るかを確かめた．次の五つの比の作り方は，走らせた後に足した読みであり，判定に使う比を置き換えない．

- **中央値 ÷ 中央値**：加工による距離の中央値を，対照の距離の中央値で割る．
- **問ごとに割った比の幾何平均**：各問の加工による距離を，その問自身の対照の距離で割り，問と加工について幾何平均を取る．
- **対照の上位1%を除いた比**：対照の距離が上位1%に入る問を，分母の平均から除く．
- **対照を別の問・別の画像にした比**：Wani らの形の対照に対する比である．
- **対照を同署名の別の問にした比**：分母を，1 から [§4.4](#44-操作の確認整合は表現をどう変えたか) の同署名の類似度を引いた値にする．画像を加工も入れ替えもしない尺度である．

| 問ごとに割った比の幾何平均 | 11.81 | 9.44 | 16.40 | **−2.37** [−3.70, −1.05] | **+4.59** [+2.68, +6.49] | **−6.96** [−8.38, −5.53] |

| 対照を同署名の別の問にした比 | 1.59 | 1.10 | 6.45 | −0.49 [−1.11, +0.13] | **+4.86** [+3.84, +5.88] | **−5.35** [−6.28, −4.42] |

- **向きは，どの比の作り方でも同じである．** 六つの比の作り方のすべてで，proposal < baseline < ablation の順に並び，proposal − baseline は5つの乱数種すべてで負になり，ablation との二つの差は区間が 0 を含まない．
- **proposal − baseline の区間は，対照を同署名の別の問にした比を除いて 0 を含まない．** 差が無くても，5つの乱数種が同じ符号に揃う確率は 1/16 ある．
- **差の大きさは，対照が同じ質問に別の画像を付けたものである四つの比の作り方のあいだでも約2倍変わる．** 中央値 ÷ 中央値と問ごとに割った比では −2.2〜−2.4pt で，判定に使う比での差の半分ほどになる．proposal の対照は右に裾を引く（→ 対照の分布の形の表）ので，proposal では平均 ÷ 平均が中央値 ÷ 中央値をほとんど上回らない（9.92 対 9.69．baseline は 14.75 対 11.89）．上位1%の問を除いてもほぼ変わらないので，効いているのは少数の外れた問ではない．
- **最後の二つの尺度には，それぞれ偏りがある．** 別の問・別の画像の対照は，異署名どうしを引き離した proposal で大きくなり，表現の集まった ablation で小さくなる（判定に使わない理由は，測る量の段落に書いた）．同署名の別の問どうしの距離は，画像ではなく問を入れ替えた距離である．

**Cohen's d は，群の比較に使えない．** d は字面では比と逆を向く．8族すべてで proposal のほうが 0 に近く，うち6族で baseline との差の区間が 0 を含まない．

| 平行移動 | −5.56 | −3.42 | −6.36 | **+2.14** [+1.80, +2.47] |
| 余白付加と切り出し | −5.06 | −3.38 | −5.13 | **+1.67** [+1.20, +2.14] |
| 縮小 | −3.02 | −1.77 | −4.04 | **+1.25** [+1.15, +1.34] |
| 縮小と余白 | −2.31 | −1.56 | −2.61 | **+0.75** [+0.57, +0.94] |
| 回転 | −2.28 | −1.63 | −2.25 | **+0.65** [+0.50, +0.80] |

| 文字なしの重ね書き | −2.86 | −1.70 | −3.44 | **+1.16** [+1.05, +1.27] |
| 23 通りすべて | −5.46 | −4.92 | −4.35 | +0.55 [−0.83, +1.93] |

加工による距離の平均を $\mu_D$，対照の距離の平均を $\mu_C$，二つを合わせた標準偏差を $\sigma_p$ とし，平均 $\mu_D$ を $\mu_C$ で割った比を $R$ と書く．d は

$$
d = \frac{\mu_D - \mu_C}{\sigma_p} = -\frac{1 - R}{\sigma_p / \mu_C}
$$

と書き直せる．比 $R$ は 0.02〜0.5 なので，分子 $1 - R$ は群によってあまり変わらない．d の大きさはほぼ，標準偏差 $\sigma_p$ を平均 $\mu_C$ で割った値で決まる．

- **加工による距離の広がりに，baseline と proposal の差は見られない．** 対照の平均で割った加工による距離の標準偏差は，平行移動で 0.056／0.064／0.079，23 通りすべてで 0.135／0.092／0.180 である．proposal − baseline の区間は，どちらも 0 を含む．
- **対照の分布の形は，proposal だけ違う．** 平均に対して横に広く，右に裾を引く．どの量も，乱数種ごとの値の範囲が群のあいだで重ならない．

| 第16層の対照（乱数種の平均） | baseline | proposal | ablation |
| --- | --- | --- | --- |
| 変動係数 | 0.46 | 0.78 | 0.34 |
| 歪度 | 1.43 | 2.75 | 0.91 |
| 90% 点と 10% 点の比 | 3.10 | 5.45 | 2.39 |
| 上位10%の問が占める，距離の総和の割合 | 19.9% | 28.2% | 16.9% |

- **proposal では，合わせた分散のほとんどが対照から来る．** 平行移動では，対照の標本は加工の標本の 1/8 しかない．それでも，合わせた分散に対照が占める割合は 89／95／70% である．
- **23 通りすべての d で3群の差が見えないのは，標本数による重みのためである．** 加工の標本は対照の 23 倍あるので，baseline と ablation の合わせた分散はおもに族どうしの距離の違いで決まり，対照の占める割合は 37%・15% である．proposal では 76% を占める．標本数で重みを付けずに二つの分散を等しく合わせると proposal − baseline は +0.90 [+0.73, +1.07] に，対照の標準偏差だけで割る（Glass の Δ）と +0.70 [+0.64, +0.77] になる．
- **加工した表現が，対照の領域へ入り込んだわけではない．** 分布の形を仮定しない重なりで見ると，proposal の重なりは増えていない．加工による距離が対照の距離を下回る確率（すべての組み合わせについて）は 99.07／99.18／98.41% で，proposal − baseline は +0.11 [−1.02, +1.24] である．同じ問の画像を入れ替えたときより小さく動いた対の割合は 99.42／99.84／98.88% である．

**d が 0 に近づいたのは，対照の分布が広がって分母が伸びたからである．** 加工による動きが対照に近づいたからではない．群ごとに対照の変動係数が 0.34 から 0.78 まで違う以上，標準偏差で割る d は，群を比べる量としては使えない．

**答えが同じでも，表現は動く．** baseline の第16層で，答えが変わらなかった対だけで集計した比は，指示文の重ね書きで 34.9% である．同じ問の画像を入れ替えたときより大きく動いた対は，指示文の重ね書きで 5.5%，無作為な文字列で 2.8% ある．proposal では，どちらも 0.3% 未満である（乱数種による揺れが大きく，区間は 0 を含む）．

**最終層の比と答えでは，幾何的な加工について3群の差は見られない．** 判定に使う比と同じ作り方で見ると，第32層の幾何的な5族では，三つの差の区間がすべて 0 を含む．proposal − baseline の平均は 0.8pt 以内である．答えが変わった割合と正解率も，幾何的な加工ではどの差も区間が 0 を含む．23 通りすべてで見ても，第32層の比（proposal − baseline −0.12pt [−0.51, +0.27]，proposal − ablation +0.10pt [−0.44, +0.64]）と答えが変わった割合（proposal − baseline −0.14pt [−0.60, +0.32]，proposal − ablation −0.06pt [−0.60, +0.48]）はどの差も区間が 0 を含む．3本のとき 0 を外れていた第32層の比の差（−0.31pt）は，5本では外れない．ただし，分布の形を仮定しない重なりでは差が見える．加工による距離が対照の距離を下回る確率は，第32層で proposal のほうが低い（proposal − baseline は平行移動で −2.47pt [−3.97, −0.97]，23 通りすべてで −2.06pt [−3.49, −0.63]）．

文字のある重ね書き2種では，proposal が baseline より小さい．ablation の差も同じくらいの大きさだが，区間が 0 を外れるのは四つのうち一つである．

proposal − ablation は四つとも区間が 0 を含むので，[§4.2](#42-三つの群) の論理では，この低下を署名ラベルに帰属できない．3本では ablation の差も四つとも区間が 0 を外れ，同じ位置に対照学習の項を足したこと自体の効果と読めたが，5本ではそこまでは言えない．文字なしの重ね書きでは，第32層の比も答えが変わった割合も，baseline との差の区間が 0 を含む．

**この測定から言えるのは，次のところまでである．**

- 署名で整合した群は，整合前より第16層の比が小さい（−4.82pt [−7.87, −1.77]）．画像を差し替えたときの動きに比べて，加工による動きが小さい．区間が 0 を含まないのは，六つの比の作り方のうち五つである．
- ラベルを並べ替えた群では，比は整合前より大きい（+6.21pt [+2.49, +9.92]）．署名で整合した群は，並べ替えた群より比が小さく，どの比の作り方でも区間は 0 を含まない．
- 距離そのものでは，第16層で proposal のほうがよく動く（+1.97 [+1.58, +2.37]．単位は $10^{-3}$）．比とは向きが逆なので，整合が表現の安定性を高めたとは書かない．安定性は，比で見るか距離で見るかに依る．
- 最終層の比と答えでは，幾何的な加工について3群の差は見られない．文字のある重ね書きでは proposal が baseline より少し動きにくいが，これは署名ラベルには帰属できない．
- 第16層の比の差は，第32層の比と答えには見られない．区間は 0 を含むので，差が無いことを示したのではない（→ [§4.3](#43-乱数種3つのまとめ方)）．
