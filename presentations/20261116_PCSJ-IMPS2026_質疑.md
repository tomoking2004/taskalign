2026-11-17 のポスター発表（P3-15）で受けた質問のうち，議論に繋げられるものを残す．**質問の文は，発表者が自分の解釈で組み立て直したもので，質問者の言葉そのものではない．** 質問者の名前と所属は残していない．

各問の下には，研究文書（[.claude/context.md](../.claude/context.md)）のどこで何を測ったか，何を測っていないかだけを書く．どう応え，何を次に測るかは，研究文書の [§8.5](../.claude/context.md#85-掛ける場所と方向を変えても構造は使われないか) と [§8.4](../.claude/context.md#84-及ぶ範囲を広げる整合の強さ別のモデルとデータ) に移した．各問の末尾に移した先を書く．

## 1. causal attention の言語モデルを選んだのはなぜか

> causal attention の言語モデルを選んだのはなぜですか？causal である必要はなく，むしろそれが悪さをして，思い通りの結果になっていないのでは？

- causal attention は選んだ条件ではなく，使ったモデル（SmolVLM-500M-Instruct）の言語側の性質である．プロンプトは画像，質問文の順に並ぶので，画像の位置の表現は質問文を見ずに作られる．
- 質問を読み終えた位置に整合を掛けたのは，causal attention のもとで画像と質問文のすべてを参照できるのがそこだからである（[§3.3](../.claude/context.md#33-どこに掛けるか射影を挟まない中間層の一点)）．
- causal attention は3群に共通の条件である．causal attention でない言語モデルとは比べていない．
- 整合は1本のベクトルにしか掛けておらず，後段の層は Attention で他の位置から読み直せる（§3.3）．答えが第16層のこのベクトルに頼る度合いは，整合で2割前後下がった（[§5.3](../.claude/context.md#53-読み取りやすさの増加に答えの生成での利用は伴っていない)）．後段がどの位置を読んでいるかは測っていない．
- 移した先：§8.5 第1歩（相対感度を全層・全位置で測り，マップにする）．

## 2. 制約が弱いのではないか

> 制約が弱いのでは？λ を大きくしたり，層を増やしたりすれば何か変わるのでは？

- 表現への効き方は測ってある．署名の読み取り精度は 82.9% → 95.9%，分離度は baseline の 2.9 倍である（[§4.4](../.claude/context.md#44-操作の確認整合は表現をどう変えたか)・[§5.1](../.claude/context.md#51-署名の読み取りやすさは大きく上がる)）．整合する層を第8層・第24層に移しても，読み取り精度は 95.0–95.4% に着く（乱数種1つ，[§A.5](../.claude/context.md#a5-整合する層を変えた試走乱数種1つ)）．
- $\lambda$ は 0.1 の一点しか測っていない．0.03・0.3・1.0 を回す設定は `scripts/sweep.py` の `LAMBDA_VARIANTS` にあり，未実行である（[§8.4](../.claude/context.md#84-及ぶ範囲を広げる整合の強さ別のモデルとデータ)）．
- 複数の層に同時に掛けることは，学習の側では層ごとの損失の平均として実装してあるが，回していない．分析の側は一つの層に掛けた run しか読まない．
- 相対感度（答えが整合した層に頼る度合い）は第16層でしか測っていない（[§7](../.claude/context.md#7-限界)）．
- 移した先：§8.4（強さの各点で相対感度も測る）と §8.5 第1歩（第8層・第24層の2本でもマップを作る）．

## 3. 発火の位置を調べる研究を参考に，制約を掛ける場所を決められるのではないか

> どんな入力で，LLM のどの部分が発火しているのかを調べる研究は多く存在すると思う．これらの方法を参考にすれば，LLM のどこに制約を掛けるべきかが見えてくるのでは？

- 掛ける場所は，第16層の，プロンプトの末尾（質問を読み終えて答えを書き出す直前の位置）に決めた（理由は §3.3）．試したほかの場所は第8層・第24層の同じ位置だけである（§A.5）．
- 第16層で答えを動かす方向は，J-lens の考え方で求めた（[§A.4](../.claude/context.md#a4-利用が伴っていないをどう測ったか三段の測定)）．同じ計算はほかの層と位置にも当てられるが，当てていない．
- 該当しうる文献の要約が [references/](../references/) にある（`cross-modal-flow.md`・`localization-editing.md`・`atp-star.md`・`cross-modal-task-vectors.md`）．いずれも，この問いに照らして原典を読んではいない．
- 移した先：§8.5 第1歩（答えが依存する層と位置のマップを作る）と第2歩（マップから選んだ場所に掛け直す）．

## 4. 内部表現には Q の情報が強く現れているのではないか（曖昧）

> 内部表現には，Attention の QKV における Q の情報が強く現れているのでは？様々な情報が潰れた結果になっているので，そこから読み取れる情報にも限界があるのでは？

- 整合する表現は，第16層の出力にある残差の流れのベクトルで，Q・K・V そのものではない．次の第17層の Attention は，このベクトルを正規化したものから，その位置の Q・K・V を作る．
- 異なる署名どうしでも，整合前の類似度は平均 0.918 で，表現は共通の向きに大きく寄っている（§4.4）．それでも署名は線形に 82.9% 読み取れる（§5.1）．ラベルを並べ替えた群では類似度が 0.99 を超えるまで寄ったが，読み取り精度は 81.0% だった．
- 読み取れることと答えに使われることが別であることは，§5.3 の主張そのものである．
- 移した先：なし．「Q の情報」という読みそのものを確かめる測定は置いていない——聞き取りが不確かなためである．
