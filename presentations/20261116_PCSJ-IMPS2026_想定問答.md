# PCSJ/IMPS 2026 発表の手引き——想定問答

2026-11-17 版．ポスター発表（P3-15，11/17 14:00–16:00）の当日に読む要点である．74問を並べた前の版（2228a4f）から，聞かれやすい問いと，言い方を誤りやすい問いだけを残し，相対感度の計算を理解するための節を足した．処理の中身は [設計と実装](20261116_PCSJ-IMPS2026_設計と実装.md) にある．測っていないことを聞かれたら，末尾の一覧に照らして「測っていません」と答える．

## 1分の説明

視覚言語モデルは，答えの正しさだけを目標に学習されるので，内部表現がどうあるべきかは学習の目標に入っていません．Wani らは，画像を少し加工すると，答えが同じでも内部表現が大きく変わる場合があると報告しました．人間なら，画像が加工されても同じ手順で答えを導くと考えられます．そこで，答えに至る手順が同じ質問どうしの内部表現を近づけ，違う質問どうしを遠ざける損失を，通常の学習に足しました．手順は，GQA というデータセットに付いている functional program の，操作の名前の並びで判定します．結果は三つです．手順の情報は内部表現から読み取りやすくなりました．しかし正解率はほとんど変わらず，答えが内部表現に依存する度合いはむしろ下がりました．手順の情報は内部表現に表れたが，答えの生成には十分に使われていない，と考えています．

## 必ず答える問い

### この研究の貢献は何ですか

内部表現から情報が読み取れることと，その情報が答えの生成に使われることは別だ，という点を，情報を明示的に作り込んだ場合について示したことです．正解率をほとんど損なわずに手順の情報を読み取りやすくできましたが，答えが内部表現に依存する度合いは上がらず，下がりました．

補足：読み取れることと使われることの区別そのものは既に知られている（Elazar らは，既にある性質を表現から除いて予測への影響を見た）．本研究は逆に，損失で性質を足した場合を見た．

### 正解率が上がらないなら，意味はあるのですか．なぜ上がらないのですか

正解率を上げる手法としては，今回の形では効果がありませんでした．わかったのは，手順の情報を内部表現に持たせるだけでは足りず，答えの生成に使わせる工夫が要る，ということです．原因は特定できていません．手がかりは，相対感度が下がったことと，モデルが間違えた質問でも署名は高い精度で読み取れること（提案手法で 96.4%）です．誤りは別のところで起きている可能性がありますが，確かめてはいません．

### 相対感度とは何ですか

第16層の $\boldsymbol{h}$ を，最も効く向きに自分の長さの1%動かすと，最終層のベクトルが「答えを決める方向」に自分の長さの何%動くか，です．baseline の8本での 0.40 は，最大で 0.40% 動く，という意味です．大きいほど，答えの選択が $\boldsymbol{h}$ に強く依存しています．

補足：
- 実際に足して計算し直したのではなく，微分で求めた一次近似である．最も効く向きの値なので上限にあたる．
- 8本・32本・128本は，「答えを決める方向」を上位から何本使ったか．計算の中身は下の「相対感度の計算」にある．
- 評価用データの先頭 64問で平均した．8〜64問のどの問数でも，8本の低下は −24% から −30% の間にある．

### 相対感度が下がったなら，手順の情報は使われていないのですか

「使われていない」とまでは言えません．言えるのは，答えが $\boldsymbol{h}$ に依存する度合いが2割前後下がった，までで，0 になったのではありません．一次近似で捉えられない経路も否定できません．読み取りやすさが大きく上がったのに依存は下がった，という組み合わせから，「十分には使われていない」と考えています．

補足：下がった仕組みは特定できていない．ablation では下がらないので，署名の意味が関わっている．

### 読み取り精度とは何ですか．上がるのは当たり前ではないですか

$\boldsymbol{h}$ だけから署名を当てる1層の線形分類器の正解率です．10 問以上ある署名の 10,990 問・145 種を使い，約半分で学習，残りで採点しました．上がる向きは損失の定義から予想できますが，三つ確かめました．ablation では上がりません．質問文の語だけで当てた 69.7% を上回ります．損失が教えていない情報まで読み取りやすくなっています．

補足：
- 質問文の先頭4語が同じ質問を学習側と採点側に分けない場合も，提案手法と baseline の差は 14.5 ポイントで保たれた．
- 損失が教えるのは署名が同じか違うかだけである．署名に含まれる操作の種類を当てると，46 種をすべて当てた割合は 36.3% → 44.5%（ablation 32.7%）．

### ablation とは何ですか

整合損失を同じ強さで掛けますが，バッチの中で署名のラベルを無作為に並べ替えた群です．提案手法が baseline と違うだけでは，対照学習の項を足したこと自体の効果かもしれません．ablation とも違って初めて，署名の意味による効果だと言えます．

補足：ラベルが署名でなければならないか（yes/no のような粗いラベルでも同じか）は確かめていない．ablation の $\boldsymbol{h}$ は，対の別なくコサイン類似度の平均が 0.99 を超え，全部が同じ向きにそろった．

### 正解率に差は無いのですか

「差が無い」とは言っていません．差は −0.06 ポイントで，95% 信頼区間 [−1.81, +1.70] が 0 を含むので，向きを決められません．言えるのは，下がったとしても最大で 1.81 ポイント，までです．予稿の「有意な差はない」も同じ区間についての記述です．

### Wani らの問題を解決したのですか

解決したとは言えません．Wani らに倣った動きの比は，14.75% から 9.92% に小さくなりました．しかし距離そのものは提案手法のほうが大きく，加工で約3倍，別の画像で約5倍です．分母のほうが大きく伸びたので，比が下がりました．言えるのは「画像を替えたときの動きに比べて，加工による動きが小さくなった」までです．

補足：動きの比は，加工の前後の $\boldsymbol{h}$ のコサイン距離を，同じ質問に別の画像を付けたときの距離で割った値．加工は Wani らに倣った 23 通り．最終層（第32層）の比では差の区間が 0 を含む．

### 署名とは何ですか．人間の手順なのですか

GQA の各質問に付いている functional program の，操作の名前の並びです．“What's the girl holding?” なら，女の子を選ぶ，持っている物へたどる，それが何かを答える，の3段です．対象（girl など）は捨てます．残すと同じ署名の対がほとんど同じ質問になり，近いのが当たり前になるからです．推論のときには要りません．

補足：GQA の原典は，これを人間の手順とは呼んでいない．人間が実際にこの手順で答えているかは検証していない．

### なぜ第16層の，入力の末尾なのですか

第16層は全32層の中間の一点で，最良だとは示していません．末尾は，画像と質問文のすべてを参照でき，答えの最初のトークンが選ばれる位置です．

補足：乱数種1つの試走で，第8層・第24層の読み取り精度は 95.4%・95.0%，第16層は 95.6%（同じ乱数種）．相対感度は第16層でしか測っていない．

### どんなモデルを，どう学習したのですか

SmolVLM-500M-Instruct です．視覚エンコーダが SigLIP-B/16，言語モデルが SmolLM2-360M で，約5億パラメタです．LoRA は使わず，全パラメタを学習率 $10^{-5}$ で学習しました．GPU 1枚で3群 × 乱数種を回せる大きさとして選びました．1回の学習は RTX 5090 で約2時間53分です．

### 正解率 53.5% は低くないですか

ほかの手法とは比べていません．軽量なモデルに，画像を分割せず 512×512 で入れ，1エポックだけ学習した条件の値です．見たいのは，同じ条件にそろえた3群の差です．

補足：このモデルの論文は，小さいモデルでは画像の分割が性能を上げると述べている．本研究は末尾の位置を正確に求めるために分割を切った．

### ほかでも成り立ちますか．今後は何をしますか

わかりません．1つのモデル，1つのデータセット，1つの層，1つの $\lambda$ での結果です．今後は二つです．手順の情報を答えの生成に使わせる工夫と，結果の及ぶ範囲の確認（$\lambda$ や層を変える，署名の代わりに別のラベルで整合する）です．

## 相対感度の計算

口頭の答えではなく，自分が計算の中身を理解しておくための節である．中身はコードで確かめた．

**問い．** 答えを選ぶ計算は，$\boldsymbol{h}$ にどれだけ頼っているか．

**登場するもの．**

- $\boldsymbol{h}$：第16層の，入力の末尾の位置のベクトル（960 次元）．
- $\boldsymbol{r}$：同じ位置の最終層（第32層，正規化の後）のベクトル．出力層の重み行列 $\boldsymbol{W}$ を掛けると，各トークンのスコアになる．答えの最初のトークンは，このスコアで選ばれる．
- $\boldsymbol{u}$：「答えを決める方向」．長さ1の向きで，$m$ 本ある．
- $\boldsymbol{J}$：$\boldsymbol{h}$ を少し動かしたとき $\boldsymbol{r}$ がどう動くかを表す 960×960 の行列．第17層から第32層までと最終の正規化を，一次近似したものにあたる．$\boldsymbol{h}$ を $\boldsymbol{\delta}$ だけ動かすと，$\boldsymbol{r}$ はおよそ $\boldsymbol{J}\boldsymbol{\delta}$ だけ動く．

**手順．**

1. **$\boldsymbol{u}$ を作る．** $\boldsymbol{W}$ から，評価用データの正解の答えの最初のトークンにあたる 1,085 行を取り出す．平均を引いて主成分分析し，上位 $m$ 本（8・32・128）を $\boldsymbol{u}$ とする．平均を引くのは，全部の候補に共通の成分はどのスコアも同じだけ動かし，候補の選び分けに効かないからである．$\boldsymbol{u}$ は群・乱数種ごとに，そのモデル自身の $\boldsymbol{W}$ から作る．
2. **$\boldsymbol{r}$ の $\boldsymbol{u}$ 方向の動きを式にする．** $\boldsymbol{h}$ を $\boldsymbol{\delta}$ 動かすと，$\boldsymbol{r}$ の $\boldsymbol{u}$ 方向の成分（内積 $\boldsymbol{u}^{\top}\boldsymbol{r}$）は，およそ $\boldsymbol{u}^{\top}\boldsymbol{J}\boldsymbol{\delta} = (\boldsymbol{J}^{\top}\boldsymbol{u})^{\top}\boldsymbol{\delta}$ だけ動く．$\boldsymbol{\delta}$ の長さを決めたとき，これが最も大きいのは $\boldsymbol{\delta}$ を $\boldsymbol{J}^{\top}\boldsymbol{u}$ の向きに取ったときで，動きは $\lVert\boldsymbol{J}^{\top}\boldsymbol{u}\rVert\,\lVert\boldsymbol{\delta}\rVert$ になる．つまり $\lVert\boldsymbol{J}^{\top}\boldsymbol{u}\rVert$ は，「$\boldsymbol{h}$ を長さ1だけ動かしたとき，$\boldsymbol{r}$ が $\boldsymbol{u}$ の向きに最大でどれだけ動くか」である．これが「最も効く向き」の正体である．
3. **$\boldsymbol{J}^{\top}\boldsymbol{u}$ を，$\boldsymbol{J}$ を作らずに求める．** $\boldsymbol{u}^{\top}\boldsymbol{r}$ という1つの数を $\boldsymbol{h}$ で微分すると，その勾配がちょうど $\boldsymbol{J}^{\top}\boldsymbol{u}$ になる．逆伝播1回で済む．向き1本につき1回，8問ずつまとめて行う．
4. **割合に直す．**
   $$
   e = \frac{\lVert \boldsymbol{J}^{\top} \boldsymbol{u} \rVert \, \lVert \boldsymbol{h} \rVert}{\lVert \boldsymbol{r} \rVert}
   $$
   $\boldsymbol{h}$ を自分の長さの1%（$\lVert\boldsymbol{\delta}\rVert = 0.01\lVert\boldsymbol{h}\rVert$）動かすと，$\boldsymbol{r}$ の $\boldsymbol{u}$ 方向の動きは $0.01\,\lVert\boldsymbol{h}\rVert\,\lVert\boldsymbol{J}^{\top}\boldsymbol{u}\rVert$ で，これを $\lVert\boldsymbol{r}\rVert$ で割ると $0.01\,e$，つまり $e$ % になる．整合損失は $\boldsymbol{h}$ や $\boldsymbol{r}$ の長さそのものを変えうるので，割合にしないと群を比べられない．
5. **平均する．** 評価用データの先頭 64問と $m$ 本の向きのすべての組で $e$ を平均し，さらに乱数種3つで平均する．低下率（−28.0% など）は，乱数種ごとに提案手法と baseline の比を取ってから平均した値である．

**数で読む．** baseline の8本 0.4023 は，$\boldsymbol{h}$ を最も効く向きに1%動かすと，$\boldsymbol{r}$ が答えを決める向きに約 0.40% 動く，という意味である．提案手法の 0.2883 では約 0.29% で，同じ1%の動きが答えの選び分けに届きにくくなった．

**読むときの注意．**

- 微分なので，ごく小さな動きについての一次近似である．実際に動かして計算し直してはいない．
- 最も効く向きに動かした値なので，上限にあたる．その向き $\boldsymbol{J}^{\top}\boldsymbol{u}$ は，問ごと・$\boldsymbol{u}$ ごとに違う．
- 動かすのは末尾の位置の $\boldsymbol{h}$ だけで，画像や質問文の位置の第16層のベクトルは動かさない．後ろの層はそれらを注意で直接参照できるので，$\boldsymbol{h}$ を通らない経路への依存は $e$ に入らない．

## 測っていないこと

聞かれたら「測っていません」と答える．

- 追加学習をする前のモデルの正解率．比較の基準は，同じ条件で整合損失を掛けずに学習した baseline である．
- ほかの手法との比較，ほかの損失（署名を当てる分類の損失など）との比較．
- $\lambda = 0.1$ 以外の値，1エポックより長い学習，温度を固定した場合．
- 第16層以外での相対感度，末尾以外の位置．
- $\boldsymbol{h}$ を実際に動かす・壊す実験．壊しても別の層が補う現象（自己修復，McGrath ら）が報告されているので，壊す方法は採らなかった．
- ほかのモデル・データセット，画像を分割した設定．
- 署名以外のラベル（yes/no など）での整合．
